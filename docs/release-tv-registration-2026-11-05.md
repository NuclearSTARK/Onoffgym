# TV 앱 등록 안내 배포

TV 모드의 **설정 → 앱 등록** 버튼에서 QR과 휴대폰 설치 방법을 보여주는 안내 화면을 연다. 가로 TV에서는 QR을 왼쪽, 아이폰 Safari·안드로이드 Chrome의 홈 화면 추가와 알림 설정을 오른쪽에 표시한다. QR은 제공된 네이버 주소를 그대로 담은 벡터 이미지다.

안내를 보는 동안 운동 페이지 자동 넘김을 멈춘다. **← 운동 화면** 버튼 또는 Esc로 돌아오면 자동 넘김을 재개한다. 새로 접속하거나 새로고침하면 운동 화면부터 열리고, 앱 등록 버튼을 눌렀을 때만 안내 화면을 연다. 세로 TV의 배치와 축소 화면도 지원한다.

검증은 전체 자동 테스트 213개, 보안 관련 테스트 85개, `qa-tv-registration.cjs`, `qa-tv6.cjs`, Pages·Worker 빌드와 변경 파일 검사로 진행했다. 가로·세로·축소 화면의 QR을 해독해 제공된 주소와 일치함을 확인했다. 브라우저 검증의 API는 로컬 예시 응답이며 실제 회원 데이터나 알림은 변경하지 않았다.

이번 배포는 웹 화면 변경이다. API·DB·회원권 정책·TV 암호·인증 설정·푸시 구독은 변경하지 않는다. 배포 전 점검의 보완 항목과 실기기 확인 사항은 [점검 기록](pre-release-check-2026-11-05.md)에 남겼다.
