# 2026-11-03 버그 점검 — 작업본 수정

최초 버그 점검 시에는 실서비스 배포, 실제 회원 데이터 변경, 포인트·쿠폰 초기화를 실행하지 않았다. 이후 사용자가 일괄 수정·배포를 승인한 결과는 [배포 기록](release-2026-11-03.md)에 정리했다. 이번 변경은 버그 수정이며, 앞서 보류한 기능 변경 일괄 작업과 구분한다.

## 발견 및 수정

| 재현 조건 | 수정 전 | 수정 후 |
| --- | --- | --- |
| 지우기 X가 있는 회원 관리 양식에서 저장을 연속 제출 | X만 비활성화되고 저장 요청 2회 발생 | 실제 저장 버튼 비활성화, 양식 단위 중복 요청 방지. 실패 후 재시도 가능 |
| 날짜 A 요청을 지연시키고 날짜 B 조회를 먼저 완료 | A 응답이 B 화면의 기록을 덮어씀 | 최신 날짜·보기·요청에 해당하는 응답만 적용 |
| A의 캐시 확인 중 B 요청이 공용 캐시를 교체 | A 조회에 B 데이터 반환 | 요청 시작 시점의 캐시와 버전을 함께 확인. 무효화 이전 요청은 캐시를 복구하지 않음 |
| 조회 요청이 진행 중일 때 로그아웃 | 늦은 응답이 회원 화면을 다시 표시 | 로그아웃 시 진행 중 조회 무효화 |
| 같은 날짜에 21명 이상 기록 | 처음 20명만 보이고 다음 페이지 없음 | 내려받은 전체 회원 기록 표시 |
| 사진을 빠르게 두 번 누름 | 확대창 2개, 닫기 순서에 따라 스크롤 잠금 충돌 | 확대창 하나만 유지하고 정리 작업 중복 실행 방지 |
| 느린 사진 A 이후 사진 B 선택 | A가 늦게 열려 B를 덮어씀 | 마지막 선택한 사진만 확대 |
| 사진 요청 중 원래 화면을 벗어남 | 늦게 확대창 열림 | 원래 버튼이 사라졌거나 계정이 바뀌면 열지 않음 |
| 사진 압축 중 작성창 닫음 | 분리된 양식에 미리보기 URL이 남음 | 닫힌 양식의 압축 결과를 폐기하고 URL 누수 방지 |

회원 관리와 같은 저장 잠금을 공지 배너·1RM 종목 저장에도 적용했다. 운동 공개 시각의 자동 갱신은 다른 주기 갱신과 동일하게 본문 양식 작성 중 실행하지 않도록 맞췄다. 이전 계정의 사진 요청 실패가 새 계정의 사진 캐시를 지우지 않도록 요청 세대를 확인한다.

## 검증

- `npm test`: 133개 통과.
- `qa-audit.cjs`: 실제 앱을 로컬 Chromium에서 실행하고 API를 전부 가상 응답으로 대체. 중복 저장·실패 후 재시도·응답 역전·21명 표시·사진 중복/순서/압축 취소·로그아웃 회귀 검증 통과.
- 수정 전 `4794217`의 JavaScript로 교체한 동일 재현에서도 날짜 응답 역전, 다른 날짜 캐시 반환, 중복 저장, 기록 20명 제한, 사진 확대 중복·지연 열림·압축 취소 누수, 로그아웃 응답 역전을 확인했다.
- `qa-release3.cjs`: 타이머 전체화면·음소거·화면 켜짐 유지, 포인트 상한·적립 항목·수동 지급·쿠폰·탈퇴 안내, 회원 상세, 1RM 아이콘/보관, 일정 정렬, 작은 화면 관련 동작 입력 검증 통과.
- `qa-collected.cjs`: 사진 업로드 실패 후 재시도·분류·탭 간 재사용·핀치 확대, 공지 첨부, 공지 띠, TV 상태, 1RM·수업 편집 검증 통과.
- Pages·Worker·Edge 번들 빌드 및 `git diff --check` 통과.

모바일 화면 크기와 터치 입력은 Chromium에서 모의했다. 실제 iPhone Safari의 키보드·안전 영역, 실기기 푸시 수신·알림음 청취는 이번 검증에 포함하지 않았다. 운영 DB에 대해 포인트 지급·구매·사용·삭제를 수행하지 않았다.

## 후속 요청: 운영 탭 저장공간 수동 조회

앱 복귀 및 화면 갱신마다 짧은 로딩 문구가 두 개의 가로막대로 교체되어 메뉴 위치가 변하던 처리를 제거했다. 저장공간 우측에 아이콘만 있는 새로고침 버튼을 추가하고 최초 진입·앱 복귀·2분 주기 자동 조회를 없앴다. 마지막 조회 결과는 같은 계정의 탭 이동과 화면 재구성에서도 유지하며, 로그아웃·계정 변경 시 비운다. 조회 전·진행 중·성공·실패에 같은 높이의 카드와 막대 영역을 사용한다.

`qa-storage.cjs`에서 320/390px 화면, 앱 복귀, 125초 가상 시간 경과, 조회 중 화면 재구성, 연속 클릭, 오류 후 재시도 및 마지막 결과 보존을 검증했다. 저장공간 카드 높이와 아래 메뉴의 문서상 위치가 유지되었고, 버튼 클릭 외 사용량 API 호출이 없었다. 수정한 `qa-collected.cjs`, 자동 테스트 133개, Pages·Worker 빌드도 통과했다. 이 단계에서는 실서비스에 배포하지 않았다. 후속 배포는 위 배포 기록을 참고한다.
