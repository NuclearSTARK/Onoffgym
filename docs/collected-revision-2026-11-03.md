# 모아둔 수정사항 반영 (2026-11-03 한국 시간)

회원 서비스는 GitHub Pages + Supabase다. TV 주소 단축은 취소되어 기존 주소를 유지한다. 실제 회원 데이터 정리/삭제, TV 암호, 이메일 확인/승인 정책은 변경하지 않는다. 실제 시험 푸시나 이메일은 발송하지 않는다.

## 변경

- TV별 세션 목록을 없애고 응답하는 세션이 하나라도 있으면 `● 연결됨`, 없으면 `○ 연결 확인 필요` 하나만 표시한다.
- 다가오는 수업은 작은 `COMING UP` 아래에 시간을 크게 표시하고 B/T·WOD 배지를 둔다. 진행 중·종료·선택 날짜·휴강은 상태를 구분한다.
- 오늘의 기록 사진은 날짜·프로그램 선택 아래, 회원별 기록 위에 둔다. 빈 안내는 `이 날짜의 기록이 아직 없어요.`로 중앙 정렬한다.
- 사진의 기본 구분은 `공통 (B/T·WOD)`이다. DB 한 행과 파일 하나를 두 탭에서 함께 보여준다. 기존 사진은 `수업 구분` 버튼으로 재업로드 없이 변경한다. 기존 사진을 임의로 공통으로 바꾸거나 삭제하지 않는다.
- 공지에도 최대 3장 사진을 첨부한다. 목록 대표/상세 전체/공통 확대 보기를 지원하고, 기존 사진을 유지한 채 추가·삭제할 수 있다. 공지 저장과 첨부 연결은 DB 트랜잭션이며 공지 삭제 시 기존 파일 정리 큐를 재사용한다. 공지 권한과 푸시 권한은 별개로 확인한다.
- 모든 사진은 별도의 전체 화면 dialog에서 핀치 확대·드래그·두 번 탭·원래 크기·닫기를 제공한다. `touch-action: none`과 Pointer Events로 사진만 변환하며, 뒤 화면/기존 글 dialog와 스크롤 위치는 유지한다.
- 한 화면의 사진 주소는 최대 12개씩 일괄 서명한다. 중복 요청을 합치고 압축한 업로드 이미지를 즉시 재사용한다. 같은 탭/다른 탭에서도 메모리 Blob 캐시를 사용한다. 캐시는 최대 24장, 55초이며 서버 서명 URL은 60초로 유지한다. 계정/승인 상태 변경 시 캐시와 열린 확대 화면을 정리한다. 영구 브라우저 저장소나 공개 버킷으로 옮기지 않는다.
- 공지의 CSS 반복 애니메이션을 헤더 전용 프레임 제어로 교체했다. 이동 거리를 유지하며 터치/탭/데이터 갱신 때 초기화하지 않는다. 숨김/복귀 때 경과 시간을 제외하고, 화면 너비와 글자 너비에 따라 반복 사본 수를 조절한다. 짧은 글도 빈 구간 없이 반복한다. reduced-motion 설정을 따른다. 재현한 조건을 개선한 것이며 모든 실기기 원인을 하나로 단정하지 않는다.
- 날짜/오늘로/출석은 같은 높이 한 줄로 맞춘다. 1RM 하단은 `중량 계산 · 기록` 한 줄로 고정한다.
- 저장공간 카드에는 제목·DB/사진 파일 수치·퍼센트·진행 막대만 남긴다. Free/하단 설명/월 다운로드 안내/Supabase 링크를 화면에서 제거한다. 기존 측정 방법·한도·운영자 전용 권한은 유지한다.
- 등록 일정의 연필/X 테두리를 제거하고 22px 아이콘과 44px 터치 영역으로 맞춘다. 수업 등록 S1/S2 탭은 18px Bold, 최소 높이 48px로 확대한다.
- 공휴일 여부와 관계없이 수요일에는 WOD만 등록한다. 직접 입력·복사·엑셀의 공통 검증과 DB 트리거에서 거부한다. 기존 수요일 B/T 데이터는 유지하고 신규 등록/내용 변경만 제한한다.

## 검증

- `npm test`: 107개 통과. 캐시의 TTL/LRU/계정 분리, 일괄 서명과 권한, 공휴일 수요일의 직접/복사/엑셀 공통 검증을 추가했다.
- `npm run build:pages`, `npm run build`, `npm run build:backend` 실행.
- `qa-collected.cjs`는 모의 인증/모의 API를 사용해 공통 사진·구분 변경·실패 후 성공분 재사용·탭 재사용·공지 사진·실제 브라우저 멀티터치 이벤트에 의한 사진만 확대·복귀를 검사한다. 공지 이동/숨김·복귀/탭 전환, 저장공간·TV·1RM·날짜·편집 아이콘·S1/S2도 확인한다.
- 운영 DB의 가짜 UUID/예시 주소를 쓰는 롤백 트랜잭션에서 공통 첨부·재분류·공지 권한 거부/허용·동일 저장 재시도·공지 삭제 정리 큐·수요일 차단을 확인한다. 실제 Edge와 같은 `service_role`로도 검사한다. 테스트 데이터와 파일을 남기지 않는다.
- 실제 iPhone의 시스템 제스처·앱 전환과 실물 TV는 브라우저 모의 검증과 구분하며 실기기 검증 완료로 주장하지 않는다. 사진 로딩은 중복 요청/전송 감소를 확인한 것이며 실제 회원 회선의 지연 시간을 측정한 것은 아니다.
