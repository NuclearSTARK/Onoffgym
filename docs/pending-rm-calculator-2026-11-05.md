# 배포 대기: 종목별 1RM 계산기와 탭 바 위치 보정

2026-11-05 배포 지시로 이번 배포에 포함한다. 아래 배포 대기 표현은 구현 당시 기록이며, 최종 배포 기록은 [release-2026-11-05-gender-records-ui.md](release-2026-11-05-gender-records-ui.md)를 따른다.

사용자가 배포하지 말라고 요청했다. 운영 버전 `7121fb9` / Pages `e6024ffcbc0c` / API v29는 유지한다.

- 1RM 목록 아래의 독립 계산기와 기준 동작 선택기를 제거한다.
- 각 종목 카드 전체의 기본 동작을 해당 종목 계산기 팝업 열기로 바꾼다. 카드 여백 클릭과 키보드 Enter/Space도 지원한다.
- 팝업은 해당 종목의 본인 최고 1RM을 기준으로 비율별 중량과 사용자 비율을 계산한다. 기존 lbs/kg 스위치를 유지하며 변경 시 팝업과 목록의 단위가 함께 갱신된다.
- 미기록 종목은 1RM 등록 안내를 표시한다. 추가(+), 기록, 순위 비교는 각각 별도 버튼으로 유지하며 카드 클릭과 중복 실행되지 않는다.
- 실제 기록이나 설정의 서버 쓰기는 추가하지 않는다. 프런트엔드 변경만 배포 대기한다.

Node 207개, Worker/Pages 빌드와 `qa-rm-calculator.cjs` 통과. 모의 Auth/API로 종목별 값, 비율·범위 오류·단위 전환, 미기록 등록 안내, 기록/비교/추가 버튼 분리, 카드 여백/키보드, 320/390/844/1280px 레이아웃을 확인했다. 실제 회원 기록은 변경하지 않았다.

## 탭 전환 후 네비게이션 위치

- 탭 바가 CSS bottom만 의존하지 않고 현재 보이는 화면의 하단에 맞춰 위치를 계산한다. 키보드 사용 후 레이아웃 높이가 이전 크기로 남는 상황에서도 확장된 visual viewport를 사용한다.
- 탄성 스크롤 offset은 레이아웃 경계 안으로 제한하며 핀치 확대 중에는 기본 CSS 고정 배치로 돌아간다.
- 탭 전환·스크롤 복원·팝업 종료·포커스 해제·화면 회전·화면 재진입 직후와 안정화 시점에 위치를 다시 확인한다. 문서 스크롤, 바 높이/불투명도와 safe area는 유지한다.
- Node 210개, `qa-nav-viewport.cjs`와 1RM 계산기 UI 검증 통과. 긴 페이지에서 탭 반복 전환, 0/34px safe area, 브라우저 UI 높이 변화, 키보드/팝업 종료 후 오래된 레이아웃 높이, 탄성 이동·확대·회전을 확인한다. 화면 크기 값은 모의로 재현했으며 실제 아이폰 검증은 수행하지 않았다.
