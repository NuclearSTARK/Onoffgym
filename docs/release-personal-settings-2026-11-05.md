# 개인설정·중량 단위 선택 화면 수정

2026-11-05 사용자의 배포 지시에 따라 누적 수정사항을 함께 배포한다. 이전 운영 버전은 `fdcc551` / Pages `2e963653695d` / Supabase API v28이다.

- 회원카드·쿠폰과 아래 설정 패널의 너비를 520px의 공통 열로 맞추고 페이지 패딩으로 생기던 좌우 차이를 제거했다.
- 네이비·민트·오렌지 테마에서 모바일 상단 및 데스크톱 사이드바 로고를 흰색으로 유지한다. 회원카드 등 다른 로고 색은 유지한다.
- 회원 기록, ACC 등록, 날짜별 수업 등록의 오늘 버튼만 38px에서 56px로 왼쪽 방향으로 넓혔다. 오른쪽 끝·높이·글꼴·패딩과 홈의 오늘 버튼은 유지한다.
- 중량 단위 선택은 개인설정과 같은 분할 스위치로 통일한다. 목록/계산기 제목은 소형, 설정은 기존 크기, 1RM·개인 기록·일괄 입력·TV 설정의 입력 단위는 누르기 쉬운 크기로 조절한다. 원래 폼 필드와 이벤트를 유지하며 단위 왕복 때 반올림으로 원래 중량이 바뀌지 않도록 기준 중량을 보존한다.
- 하단 네비게이션 배경 불투명도를 80%에서 70%로 낮춘다. 높이·아이콘·텍스트의 불투명도·blur는 유지한다.
- 운영자·코치는 개인설정의 회원카드·쿠폰을 기본 숨김으로 하고 앱 설정에서 켜고 끌 수 있다. 최형대의 기존 승인된 계정 ID를 읽기 전용 조회로 확인하여 해당 계정만 기본 켜짐 예외로 한다. 이름 비교를 사용하지 않으며 명시적인 선택이 기본값보다 우선한다. 일반 회원은 계속 표시한다.
- 표시 상태는 `preferences.showMembershipWallet` 불리언으로 본인 계정에 저장한다. API는 승인된 운영자·코치만 이 필드를 저장하도록 검증하며 다른 계정 ID를 받지 않는다. 기존 JSONB 병합 경로를 사용하여 다른 설정과 회원권·쿠폰 데이터를 보존한다. 스키마 변경은 없다.

검증: Node 207개, `qa-unit-controls.cjs`(전역/개인/1RM/일괄/TV 단위 선택, 중량 단위 왕복·기준값 저장·폼 호환·반응형 너비·하단 바 불투명도/높이), `qa-record12.cjs`, Worker/Edge/Pages 빌드, 모의 Auth/API UI 검사(가로/세로 정렬, 실제 테마 선택 후 흰색 로고와 새로고침, 세 화면 오늘 버튼의 치수 전후 비교 및 이동, 지갑 표시의 역할별 기본값·전환·저장·새로고침·예외 계정·기존 데이터 보존) 통과. 실제 회원·회원권·쿠폰·권한·설정 값은 테스트로 수정하지 않았다.

새 `showMembershipWallet` 필드를 처리하는 API 번들을 먼저 배포하고 Pages를 배포하는 순서를 사용한다. 자체 인증 검증과 이메일 즉시 가입 설정을 유지한다.
