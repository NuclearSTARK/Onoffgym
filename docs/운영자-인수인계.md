# 온오프짐 운영자 인수인계

## 서비스 소유권과 주소

- 회원용 앱: https://nuclearstark.github.io/Onoffgym/
- 공개 예시: 위 주소에 `?preview=1#home`을 붙인다. 실제 회원정보를 넣지 않는다.
- GitHub: NuclearSTARK/Onoffgym. 대표에게 이전한 뒤 Pages 주소·배포 경로·인증 복귀 주소를 함께 변경한다.
- Supabase: 대표 소유 onoffgym 프로젝트(`gieomcjarupbnwwehqjc`). 개발자는 초대받은 계정으로 관리한다.
- 기존 Sites 미리보기는 owner-private와 D1을 유지한다. 회원용 Supabase 앱과 계정/데이터가 별개다.

## 이메일 회원가입 설정

1. Supabase → Authentication → Sign In / Providers → Email: Email 활성화, **Confirm email OFF** 후 저장.
2. Authentication → URL Configuration:
   - Site URL: `https://nuclearstark.github.io/Onoffgym/`
   - Redirect URLs에 `https://nuclearstark.github.io/Onoffgym/auth-callback.html` 추가.
3. Authentication → Email / SMTP Settings: 비밀번호 재설정용 발신자와 SMTP를 설정한다. 비밀값은 대시보드에 직접 입력하고 GitHub·채팅에 올리지 않는다.
4. 실제 수신 가능한 주소로 비밀번호 찾기 → 메일 수신 → 링크 클릭 → 변경 후 로그인까지 확인한다. 기본 Supabase 메일 서버는 일반 회원 전체를 위한 운영용 발송으로 간주하지 않는다.

가입: 이메일·비밀번호(8자 이상)·실명·개인정보 동의 → 운영자 승인 대기 → 승인 후 이용. 이메일 가입 인증과 매번 로그인 인증 메일은 사용하지 않는다. 브라우저/기기 변경, 로그아웃, 브라우저 저장 데이터 삭제 시 다시 로그인해야 한다.

## 첫 운영자와 승인

대표와 개발자 각자 회원가입한다. 사용자와 합의한 실제 계정 UUID를 확인해 최초 두 운영자를 명시적으로 지정한다. 이메일이 같다는 이유만으로 이후 가입자에게 운영자 권한을 자동 부여하지 않는다. 첫 가입자 자동 운영자 기능도 없다.

다른 회원의 회원권·상세를 열면 상단의 ‘계정 권한 · 운영자 지정’에서 역할을 바꾼다. 자기 계정에는 현재 권한 안내만 표시한다. 이후에는 운영 → 회원 승인·권한에서 승인/이용 중지, 회원/운영자 권한, 실명 정정, 동명이인 구분 메모를 관리한다. 회원 ID는 이름과 별개여서 정정해도 같은 기록을 유지한다. 로그인 유지와 회원권 이용 권한은 별개다.

## 수업·기록·회원권

운영 → 수업 등록·수정에서 XLSX 양식을 내려받아 미리 작성하고 업로드 미리보기를 확인한다. 공개 시각은 운영 → 등록 일정 → 다음 날 운동 공개에서 변경한다. 공휴일은 기본 휴강이며 특별 수업은 시작 시각을 지정한다. 수요일은 WOD만 운영한다.

운영자는 회원 기록을 일괄 입력할 수 있다. 1RM 종목 추가·수정·분류·기본 표시는 운영 메뉴에서 관리한다. 개인 기록은 고유 회원 ID에 연결된다. 중량 기본 단위는 lbs이며 개인 설정에서 kg으로 바꿀 수 있다.

회원권은 1·3·6·12개월권과 횟수권, 휴회·재개를 지원한다. 횟수권은 하루 여러 수업을 들어도 1회 차감한다. 앱 탈퇴와 실제 체육관 회원권의 해지·환불은 별도 업무다.

## 웹 푸시

휴대폰 개인설정 → 알림 설정에서 각 기기 알림을 허용한다. 아이폰은 홈 화면에 추가한 앱에서 허용한다. 운영자는 회원 승인 요청 알림을 따로 켜고 끌 수 있다. 일반 회원은 승인 요청 알림의 수신 대상이 아니다. 이미 처리된 가입 요청은 전송 직전 다시 확인해 제외한다.

운영 → 푸시 알림 보내기에서 제목·내용 미리보기, 자기 기기 시험 또는 공지를 허용한 회원에게 발송할 수 있다. 커뮤니티 공지 작성 시 푸시 체크도 지원한다. 발송 이력의 ‘전달’은 푸시 제공자의 접수를 뜻하며 실제 화면 표시는 기기에서 확인한다. 공개 예시는 실제 발송하지 않는다.

## TV

운영 → TV 모드에서 4자리 암호·방향·색상·페이지 전환을 설정한다. 기본은 가로이며 폰 화면에서도 가로 구성을 비율대로 줄여 표시한다. 세로를 선택하면 세로 구성으로 바뀐다. TV는 회원 로그인 없이 PIN으로 접속한다. 원본 로고·날짜·시간은 화이트이며 수업 색상만 바꾼다. TV에서 따로 고른 색상은 해당 기기에 남는다.

## 탈퇴와 개인정보

회원은 승인 전·중지 상태에서도 자기 계정 탈퇴를 요청할 수 있다. 현재 비밀번호와 삭제 동의를 확인하고 모든 로그인 세션을 해제한 뒤 Auth 계정과 개인 운동·출석·회원권·일반 게시글·댓글을 삭제한다. 운영 공지는 작성자 연결을 해제해 유지한다. 마지막 승인 운영자는 다른 승인 운영자가 있어야 탈퇴할 수 있다.

개인정보처리방침의 시행일, 실제 처리위탁·국외 이전, 법정 보관 대상 여부와 백업 보관 정책은 대표가 확인한다. 웹사이트 개인정보 문의처와 대표 정보 변경도 함께 반영한다.

## 인수인계 전 확인

[테스트 체크리스트](handover-test-plan.md)의 실계정 가입·승인·다른 기기 동기화, 재설정 메일, 탈퇴, 실제 휴대폰 푸시, 실제 TV 장시간 표시를 대표가 직접 확인한다. Supabase 사용량·SMTP 한도·백업·배포 실패 확인 담당자를 정한다. GitHub/Supabase/발송 서비스 계정은 대표가 계속 접근할 수 있어야 한다.

GitHub 계정이 생기기 전 준비와 이전 순서는 [GitHub 이전 준비](github-이전준비.md)를 참고한다. 대상 아이디를 넣는 계획 도구는 실제 소유권이나 설정을 변경하지 않는다.

## 이번 화면·기록 변경 (2026-11-01)

- 하단 메뉴는 화면 아래에 항상 고정한다. 키보드 사용 중 숨기고 닫으면 복원한다. 공지 배너와 로고의 상단 고정은 유지한다. 휴강일에도 타임테이블 안내가 표시된다.
- 수업 등록은 날짜별 입력을 먼저, 엑셀 업로드를 다음에 배치했다. 관련 동작은 쉼표·세미콜론으로 구분해 연속 검색할 수 있으며 직접 입력도 가능하다.
- 운동 영상 관리는 운영 메뉴에서 바로 열린다. 운동 공개 시각은 등록 일정 안에서 관리한다.
- 나의 기록 → 1RM → 기록 이력 → 수정으로 기존 기록을 수정한다. 수업에서 연결된 1RM은 중량만 수정하며 해당 수업 결과에도 반영된다. lbs/kg 전환은 원래 중량을 보존한다.
- 커뮤니티 숫자는 공지를 포함한 미확인 게시글 수다. 본인 글은 제외하고 게시글을 열면 읽음 처리한다. 읽음은 계정별 Supabase에 저장되어 다른 기기에도 반영된다. 댓글 수나 개인 메시지 수가 아니다.

## 모바일·운동 영상 화면 보완 (2026-11-01)

- 팝업의 X는 테두리와 배경 없이 표시한다. 본문만 스크롤하며 키보드가 올라오면 보이는 화면 안으로 위치·높이를 조정한다. 닫으면 배경 스크롤을 복원한다.
- 일괄 입력의 날짜·수업·시간 입력칸은 동일한 높이를 사용한다.
- 오늘의 운동의 전체 보기/접기는 기록 수집 여부와 관계없이 오른쪽에 정렬한다.
- 운동 영상 관리 → 운영 관리로 돌아갈 수 있다. 1RM 종목의 분류·별칭을 따라 영상을 묶고 유산소, 맨몸·체조, 기타 분류를 추가한다. 분류 필터와 검색을 함께 사용할 수 있다. 기존 영상 주소·설명·기록은 유지한다.
- 가로모드 왼쪽 메뉴도 세로 스크롤할 수 있다. 나의 회원권·나의 기록으로 앱 문구를 통일했다.

## 하단 네비게이션 고정 보완

화면 하단에 메뉴를 고정하고 홈바 여백과 같은 높이의 콘텐츠 여백을 둔다. 앱 재진입·화면 크기 변경 시 보이는 화면의 아래쪽에 다시 배치한다. 키보드가 열리면 숨기고 닫힐 때 복원한다. PC·가로 화면의 왼쪽 메뉴는 기존처럼 스크롤한다.

## 운동 카드·회원권 카드·운영 화면 정리

- 홈에는 다른 탭과 같은 크기의 오늘의 운동 제목을 표시하고, 왼쪽 메뉴는 홈으로 통일한다. 왼쪽 메뉴 하단의 소개 문구와 중복 운영 바로가기는 제거했다.
- 구간의 접기/전체 보기는 운동 내용 아래 하단 줄에 둔다. 기록 종류는 왼쪽, 버튼은 오른쪽이며 처음에는 전체 내용을 보여준다.
- 나의 회원권은 등록된 데이터에 따라 1개월 블루, 3개월 민트, 6개월 퍼플, 1년 골드, 횟수권 오렌지 카드로 표시한다. 휴회·만료·시작 전·미등록 상태와 마지막 횟수 이용 상태도 구분한다. 회원권 데이터와 접근 정책을 변경하는 기능은 아니다.
- 커뮤니티 말머리는 종류별로 색상을 구분한다. 고정 공지 표기는 📌 공지사항이며 고정 기능은 유지한다.
- 등록 일정의 공개 시각 설정에서 현재 시각 옆의 변경할 시각을 입력하고 저장한다. 등록된 수업 카드와 간격을 두었다.
- 하단 ONOFF CROSSFIT 아래에는 SINCE 2022를 표시한다.
- 하단 메뉴는 CSS로 화면에 고정한다. 스크롤 끝에서 바깥으로 당겨 페이지가 튕기지 않게 처리하며 가로 스와이프·확대·내부 스크롤은 허용한다.
