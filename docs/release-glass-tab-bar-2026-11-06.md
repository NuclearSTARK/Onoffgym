# 테마별 유리 하단 탭바

승인된 레퍼런스를 실제 모바일 하단 메뉴에 적용했다. 아이콘 아래에 홈·회원 기록·나의 기록·커뮤니티·운영 문구를 표시한다. 기존 권한에 따라 일반 회원은 4개, 운영자·코치는 5개 메뉴를 표시한다. 네이비 블루·블랙 민트·차콜 오렌지의 공통 테마 변수로 바탕색과 글자색을 맞추고, 선택 배경은 은은한 유리 효과로 표현한다.

바깥 바와 안쪽 선택 배경은 같은 R30을 사용한다. 320px처럼 좁은 화면에서는 두 반경을 함께 줄여 아이콘 중심과 선택 배경의 중심을 유지한다. 선택 배경의 양쪽 모서리가 서로 다른 스프링으로 이동하며, 연속 클릭은 현재 위치와 속도에서 이어진다. 라우트가 승인된 뒤 선택 상태를 갱신하므로 기존 저장하지 않은 내용 확인 흐름을 유지한다. 기존 버튼을 재사용해 키보드 포커스를 유지하고, 동작 줄이기 설정에서는 즉시 이동한다. 화면이 숨겨지거나 애니메이션이 끝나면 프레임 요청을 중지한다.

하단 안전영역과 보이는 화면 하단 고정 처리를 유지하면서 탭바 둘레에 여백을 추가한다. 세로모드에서만 표시하며 기존 가로모드 사이드 메뉴, 로그인·가입 대기·개인정보 및 알림 안내·타이머 전체화면의 표시 규칙을 유지한다. 버튼 배지와 기존 페이지별 권한·데이터 저장 처리는 유지한다. DB·API 변경은 없다.

## 검증

- 자동 테스트 215개 통과. 새 테스트는 연속 탭의 위치·속도 연속성, 반대 방향 전환 후 수렴, 큰 이동에서 선택 배경의 경계 및 최소 크기를 검증한다.
- Pages 및 Worker 빌드 통과. 새 모듈과 스타일도 기존 릴리스 지문에 포함된다.
- 브라우저에서 3개 테마, 운영자·코치 5개 및 회원 4개, 메뉴명 위치, 동일한 반경, 연속 탭, 하위 페이지 선택 상태, 개인설정 등 별도 페이지의 선택 배경 숨김, 동작 줄이기, 320–760px 및 가로모드 전환을 확인했다.
- 기존 하단 위치 검사도 새 부유형 탭바 치수에 맞췄다. 긴 화면 스크롤 후 탭 전환, 하단 안전영역 0/34px, 키보드·팝업 종료 후 오래된 화면 높이, 화면 확대 및 탄성 스크롤 범위를 검증했다.
- 브라우저 검증은 로컬 예시 API와 모의 화면 높이를 사용했으며, 실제 회원 기록·알림·권한은 변경하지 않았다. 실제 iOS 기기 테스트를 수행했다는 의미는 아니다.

## 높이 및 하단 위치 조정

가로 폭과 좌우 여백은 유지하고 탭바 높이를 80px에서 68px, 안쪽 선택 배경을 60px에서 52px로 줄였다. 탭바 아래 추가 여백은 10px에서 0px로 줄여 기존 배포본보다 하단 끝이 10px 아래에 위치한다. 하단 안전영역은 유지한다. 두 모서리는 줄어든 높이에 맞춰 동일한 R26을 사용하며, 아이콘 크기와 글자 크기는 유지하고 세로 배치만 조정한다. 기본 고정 위치와 보이는 화면 하단을 따라가는 위치에 같은 여백 변수를 사용하고, 본문 하단 예약 공간도 줄였다. 기존 하단 위치 브라우저 검사와 자동 테스트·Pages 빌드를 다시 통과했다.

## 추가 크기 및 위치 조정

탭바 높이를 68px에서 60px, 선택 배경을 52px에서 44px로 줄였다. 좌우 여백은 각각 12px에서 24px로 늘려 전체 가로 폭을 24px 줄였다. 반경은 바깥·안쪽 모두 R22로 맞췄다. 하단 간격은 안전영역에서 최대 8px를 줄여 더 아래에 배치하고, 안전영역이 없는 기기에서는 화면 하단을 넘지 않도록 0px로 제한한다. 아이콘과 글자 크기는 유지하며 세로 간격과 본문 하단 예약 공간을 함께 조정한다.

최종 높이는 63px로 조정했다. 선택 배경 높이도 47px로 맞추고, 가로 폭·하단 위치·R22·아이콘·글자 크기는 유지한다.
