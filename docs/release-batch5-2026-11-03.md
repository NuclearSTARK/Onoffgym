# ONOFF 배포 — 2026-11-03 저녁 요청

B/T는 파랑, WOD는 주황으로 탭·수업 구간·회원 기록·수업 배지를 통일했다. ACC는 같은 배경 투명도에 보라색 테두리를 유지한다. 회원 이용/휴회 테두리는 4px로 두껍게 표시한다.

운동 영상 카드 우측에 수정/삭제 아이콘을 추가하고 제목을 수정할 수 있게 했다. 이름을 여러 번 바꿔도 이전 이름을 별칭으로 유지하므로 기존 수업의 영상 연결과 1RM 데이터는 유지된다. 분류 선택과 관리 버튼 높이/하단을 맞췄다.

모든 공용 팝업에서 상단 로고·도구·흐르는 공지의 화면 위치를 유지하도록 헤더를 고정하고 실제 헤더 높이를 콘텐츠 여백에 반영한다. 쿠폰에도 회원카드와 동일한 로고를 사용한다. 앱 색상은 선택한 테마를 사용하고 OS 색상 모드에 따른 자동 변환을 억제한다. 기기 디스플레이의 색상 보정은 앱에서 변경하지 않는다. 로딩 문구는 “당신의 열정을 켜는 중…”으로 바꿨다. 개인정보처리방침 상단의 임시 운영자 확인 안내 상자만 제거했다.

이번 배포 이후 새로 승인되는 회원은 첫 접속 시 알림 켜기/나중에 설정 안내를 본다. 이미 이 기기에서 구독 중인 회원은 건너뛴다. 아이폰 일반 브라우저에는 홈 화면 추가 안내를 제공한다. 기존 승인 회원은 소급 적용하지 않는다.

승인된 회원 모두 운동 번개 작성 시 시작 날짜·시간과 홈 배너 고정/공지 푸시 스위치를 사용할 수 있다. 기존 공지 아래 빨간 흐르는 배너를 추가하고 날짜순으로 고정 글을 표시한다. 문구는 한국 시간 기준 “운동 번개 MM/DD HH:mm 함께 운동해요”로 고정한다. 배너와 푸시는 해당 글을 연다. 작성자/운영자가 고정을 해제할 수 있다. 동일 게시글 재시도는 푸시를 중복 발급하지 않는다. 발송 직전 작성자 승인 상태·글 존재·수신 설정을 다시 확인한다.

포인트 기능을 끄면 상점 아이콘/바로가기/포인트 표시를 숨기고 상점 직접 접근은 홈으로 보낸다. 기존 잔액/쿠폰과 운영자 관리 메뉴는 유지한다. 수동 지급 버튼과 동일한 크기의 전체 회원 초기화 버튼을 우측에 배치하고 하단 보유 상한 설명을 제거했다. 초기화는 운영자 확인 후 전체 잔액만 0P로 변경한다. 쿠폰과 기존 내역은 유지하며 조정 내역과 요청 감사 기록을 남긴다. 요청 ID로 중복 초기화를 방지하고 적립·교환·차감과 잠금 순서를 통일한다.
