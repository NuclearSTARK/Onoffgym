# TV 암호 입력 아래 빈 버튼 제거

TV 로그인 화면에서 공통 입력 도우미가 비밀번호 보기 버튼을 추가했지만, TV는 그 버튼의 스타일을 불러오지 않아 입력칸 아래에 빈 박스가 나타났다. TV 페이지에서 불필요한 입력 도우미와 스타일 참조를 제거해 숫자 4자리 암호 입력칸과 제출 버튼만 표시한다. 일반 회원 로그인 화면의 비밀번호 보기 기능은 그대로 유지한다.

제출 중 비활성화할 대상은 `button[type=submit]`으로 명확히 지정했다. 320px·390px·1920px 브라우저에서 빈 버튼 제거, 암호 마스킹, 가로 넘침 없음, 제출 중 잠금과 잘못된 암호의 재시도를 확인했다. TV 앱 등록 안내·복귀·PIN 접속의 기존 브라우저 검사와 Pages·Worker 빌드도 확인한다. 모든 로그인 요청은 로컬 예시 응답이며 실제 TV 암호·세션·회원 자료는 변경하지 않는다.
