# 1RM·NAMED WOD 기록 숫자 키패드

1RM 성공 중량에 `inputmode="decimal"`을 지정해 소수점이 있는 중량도 숫자 키패드로 입력하도록 한다. NAMED WOD의 분·초·라운드·추가 횟수에는 `inputmode="numeric"`을 지정한다. Cindy를 포함해 종목을 전환하거나 기존 기록을 수정해 입력칸이 다시 생성될 때도 같은 설정을 사용한다. 메모의 일반 텍스트 입력과 날짜·기존 검증·저장 형식은 유지한다.

브라우저에서 1RM 소수점 중량의 유효성, Annie의 분·초, Cindy의 라운드·횟수, 종목 왕복 전환 후 입력 모드, 메모의 한글 입력 보존을 확인했다. 모든 API는 로컬 예시 응답을 사용해 실제 기록은 저장하지 않았다. 관련 자동 테스트 17개와 Pages·Worker 빌드가 통과했다. 웹 입력 속성만 변경하며 DB·API·저장된 회원 기록은 변경하지 않는다.
