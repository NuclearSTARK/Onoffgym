# 탭바 위치·수요일 시간표 수정

키보드나 앱 복귀 이후 오래된 화면 높이가 남을 때 탭바가 화면 중간에 뜨는 문제를 수정했다. 탭바는 브라우저의 하단 고정을 사용하고, 키보드를 닫은 뒤 숨김 상태가 계속 남지 않도록 처리한다. 높이 63px과 기존 스와이프·스크롤 숨김 동작은 유지한다.

매주 수요일의 11:00 WOD를 OPEN GYM으로 바꾸고 12:00 중복 표시를 합쳤다. 수요일 오픈짐은 11:00–16:30으로 표시하며 다른 요일과 휴강일·별도 특별 수업 규칙은 유지한다. 공유 시간표 함수를 사용하는 Edge API v34에도 반영했다. 운영 DB와 실제 회원 기록은 변경하지 않는다.

검증: 단위/API 테스트 235개 통과, Edge·Cloudflare 빌드 통과. 탭바의 높이 불일치 양방향, 키보드·팝업 종료, 앱 복귀, 스와이프·스크롤과 여러 화면 크기를 재현했다. 수요일 시간표의 휴대폰·데스크톱 표시와 안내 문구를 모의 API로 확인했다. 실제 iPhone의 운영체제 전환을 직접 시험한 것은 아니다.
