# 칠판 사진 기록 · GPS 출석

## 배포 상태와 최초 설정

GPS 출석은 확인된 체육관 주소(부산광역시 기장군 일광읍 화용길 157, 1층)의 도로명 주소 좌표 35.2851377, 129.2170302를 중심으로 반경 200m를 적용합니다.
주소 좌표 출처: https://findby.co.kr/details/46046-267104220365-st-652b10b08c641f9e388dd41c
운영 → 사진 기록 · GPS 출석에서 반경과 기준점을 바꾸거나 제한을 끌 수 있습니다. 체육관 현장에서 ‘체육관 현재 위치로 설정’ 후 저장하면 기기에서 확인한 위치로 보정합니다.

AI 사진 인식에는 별도 OpenAI API 계정·결제 설정이 필요합니다. ChatGPT 구독과 다릅니다.
1. https://platform.openai.com/ 에서 API 계정·결제/사용 한도를 설정합니다.
2. 해당 프로젝트에서 API 키를 만듭니다. Responses API 사용 권한이 필요합니다.
3. Supabase 프로젝트의 Edge Functions → Secrets에 이름 `OPENAI_API_KEY`, 값은 발급받은 키로 저장합니다.
   https://supabase.com/dashboard/project/gieomcjarupbnwwehqjc/functions/secrets
4. 앱을 다시 열고 운영 → 사진 기록 · GPS 출석에서 ‘AI 연결: 준비 완료’를 확인합니다.
키를 채팅·GitHub·앱 입력창에 붙여넣지 않습니다. 서버 환경 변수만 사용합니다.
현재 모델은 `gpt-4.1-mini`, Responses API 이미지 입력 및 구조화 출력입니다. 실제 계정·키가 없으면 자동 인식은 동작하지 않고 직접 입력/사진 보관이 가능합니다.

## 운영자: 칠판 사진에서 기록 남기기

1. 회원 기록 → 날짜·B/T 또는 WOD 선택 → 기존 사진 올리기.
2. 사진 저장 후 ‘사진에서 기록 등록’ 화면에서 ‘AI로 사진 읽기’를 누릅니다. 기존 사진은 사진 아래 ‘칠판 기록 읽기 · 수정’으로 엽니다. 공통 사진은 B/T·WOD 모두에서 보입니다.
3. 목록에서 이름·결과를 확인합니다. 수정할 행을 펼쳐 수업 구간, 이름, 회원 연결, 결과, Rx’d/Scaled, 메모를 고칩니다. 원본 사진 버튼으로 대조할 수 있습니다.
4. 팀 와드는 한 행에 팀원들을 추가합니다. 해당 구간에 Team of 2/3가 있으면 그 인원수를 확인합니다. 팀 결과는 하나만 저장되며 개인 순위에 섞지 않습니다.
5. 미가입·동명이인은 미연결로 둡니다. 가입이 완료되면 같은 사진의 기록을 열어 회원을 직접 연결하고 다시 등록합니다. 아직 등록된 동명이인이 없더라도 이름 일부만으로 자동 연결하지 않습니다.
6. 이름을 확실히 확인한 경우에만 ‘별칭 기억’을 선택합니다. 이후 같은 칠판 이름은 그 회원에게 연결됩니다. 동명이인은 ‘형대(최)’·‘형대(김)’ 등 서로 다른 표기를 권장합니다. ‘기억한 칠판 이름 관리’에서 잘못 기억한 별칭을 해제할 수 있습니다. 기존 기록의 잘못된 연결은 별도로 수정합니다.
7. 원본 대조 후 확인 완료를 선택하고 ‘확인한 기록 등록’을 누릅니다. 필요 없는 행은 제외합니다. ‘초안 저장’은 회원에게 보이지 않습니다. 전체를 직접 대조했다면 전체 확인 버튼으로 일괄 확인할 수 있습니다.
8. 회원은 나의 기록 → 운동 기록에서 연결된 결과를 봅니다. 미연결 이름은 회원에게 공개되지 않으며 팀원의 이름은 공개 동의를 반영합니다.

잘못 등록했다면 같은 사진 → ‘이 사진의 기록 등록 취소’. 원본 사진·수동 입력한 기록은 그대로입니다. 취소한 기록은 수정 후 다시 등록할 수 있습니다. 운영자는 수정 이력을 볼 수 있습니다. 사진 기록 기능을 끄면 기존 사진만 올리는 흐름으로 돌아갑니다.

자동 인식은 하루 운영자별 30회, 최소 20초 간격입니다. 원본 사진 파일만 서버가 읽으며, 임의 외부 URL은 받지 않습니다. 결과는 저장된 초안을 다시 열 수 있고 재인식이 저장된 수정 내용을 덮어쓰지 않습니다. 흐릿한 필기·지운 숫자·중량 단위 등은 직접 확인해야 합니다. 실제 사진 인식률·API 결제 연결은 계정 설정 후 현장 확인이 필요합니다.

## 회원: GPS 출석

체육관에서 출석 버튼 → 위치 권한 허용 → 거리 확인 후 출석 완료.
위치 정보는 출석 요청 때만 조회하며 회원 좌표를 DB에 보관하지 않습니다. 위치는 2분 이내, 정확도 100m 이하인 측정값을 사용합니다.
권한 거절·오차가 크면 위치 권한/정확한 위치를 켜고 창가 등에서 다시 시도합니다. 실패한 요청으로 횟수권은 차감되지 않습니다.
운영자는 운영 → 사진 기록 · GPS 출석 → 위치 확인 예외 출석에서 실제 방문한 회원과 사유를 입력해 대신 처리할 수 있습니다. 관리 이력에 남습니다.
하루 한 번 차감, 같은 날 여러 수업은 추가 차감 없음, 출석 취소 시 해당 회원권의 횟수 복구 규칙은 유지됩니다.
GPS 위치 조작을 완전히 막는 기능은 아닙니다.

## 적용 내역

DB migration: `20261110235133_onoff_photo_records_geofence.sql`.
Supabase `onoff-api` v35. 새 테이블은 RLS를 켜고 anon/authenticated의 테이블·RPC 권한을 제거했습니다. 서비스 역할이 검증된 서버 요청만 처리하므로 공개 RLS 정책은 의도적으로 두지 않습니다.
자동 사진 인식의 실사용 검증은 OpenAI API 계정/키가 준비된 후 진행합니다. 이번 배포에서 실제 AI 호출로 요금을 발생시키지 않았습니다.

## 검증

Node 단위·API 테스트, PGlite의 실제 PL/pgSQL 실행(초안/공개/취소·별칭 충돌·동시 수정·권한·출석 1회 차감·탈퇴 시 연결 제거), 격리된 모바일 브라우저 테스트를 수행합니다. 실제 회원 기록이나 알림을 테스트로 생성하지 않습니다.
`npm test`, `npm run build:backend`, `npm run build:cloudflare`, `npm run build`.
`python tests/browser/record-tools.py`는 로컬 `pages-dist`와 가짜 인증/API를 사용합니다. 실제 AI 요청·회원 변경은 하지 않습니다.
