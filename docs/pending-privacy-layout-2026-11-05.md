# 배포 대기: 개인정보 안내 화면 축약

2026-11-05 배포 지시로 이번 배포에 포함한다. 아래 배포 대기 표현은 구현 당시 기록이며, 최종 배포 기록은 [release-2026-11-05-gender-records-ui.md](release-2026-11-05-gender-records-ui.md)를 따른다.

2026-11-05 사용자가 긴 개인정보 안내 화면을 정리해 달라고 요청했다. 로컬 수정만 진행하고 배포하지 않았다.

- 제목을 `개인정보 안내`로 줄이고 수집 항목·목적·보관 기간을 짧은 요약으로 배치했다.
- 기존 수집·이용/공개 안내 원문은 기본 닫힘인 네이티브 details 안에 보존했다. 같은 영역에서 개인정보처리방침 전문을 열 수 있다. 회원가입과 전문 문서의 원문은 그대로 유지한다.
- 성별 선택, 필수 나이 확인·수집이용 동의, 선택 회원 간 공개 동의를 요약 바로 아래에 배치했다. 동의 거부 시 이용 범위 안내는 남겼다. 저장 버튼은 전체 폭으로, 로그아웃/삭제 링크는 아래 한 줄로 정리했다.
- 입력 이름·기존 선택값·필수 검증·선택 공개 동의의 기본값 및 API는 변경하지 않는다. 안내 내용/동의 버전·정책·DB 변경은 없다. 이전 성별/승인 이력·1RM 팝업·네비게이션·사진 포커스 로컬 수정을 보존한다.
- 390×844 모의 휴대폰에서 접힌 기본 패널은 높이 711px로 성별·동의·저장·하단 링크까지 한 화면에 표시된다. 더 좁거나 가로인 화면은 문서 스크롤을 유지한다.
- 임시 Playwright에서 기존 세 역할의 필수 검증·선택 동의 유지·저장/재접속, 기존 동의 설정 열기/닫기, 상세 안내 펼치기/접기·전문 열기/닫기, 320/390/844px의 가로 넘침 없음을 확인했다. 실제 Auth/API 쓰기는 전부 모의 응답이다.
- Pages/Worker 빌드 및 `git diff --check` 통과.
