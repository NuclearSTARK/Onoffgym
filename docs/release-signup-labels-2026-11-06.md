# 회원가입 항목 정렬 및 필수 표시

회원가입의 실명·성별·이메일·비밀번호·비밀번호 확인 순서를 유지하고, 모든 제목을 기존 실명 제목과 같은 11px·600 굵기의 왼쪽 정렬로 맞췄다. 성별의 '필수' 문구를 빨간색 `*`로 바꾸고 다섯 제목 옆에 같은 글자 크기·색상·간격의 표시를 붙였다. 필수 나이 확인·개인정보 동의에도 `*`를 표시하며 선택 공개 동의에는 표시하지 않는다.

회원가입에만 적용되는 스타일과 `genderField()`의 선택 옵션을 사용한다. 개인정보 안내와 기존 회원 관리의 성별 표시는 기본 동작을 유지한다. 입력 필수 속성·자동 완성·비밀번호 조건·선택 동의의 선택 가능 여부와 인증 처리는 유지하며, 별표는 장식으로 처리해 제목에 별표가 읽히지 않게 한다. DB·Auth 설정 변경은 없다.

자동 테스트 220개 및 Pages 빌드가 통과했다. 브라우저에서 320/390/760/1280px와 세 테마의 순서·왼쪽 위치·글자 크기·별표 색상과 간격·가로 넘침을 확인했다. 필수 항목 누락에 대한 기본 검증과 선택 동의를 끈 상태의 유효성, 로그인 화면으로 전환 시 회원가입 표시가 사라지는 것도 확인했다. 모든 인증 요청은 예시 응답으로 차단했으며 실제 계정 생성이나 회원 정보 변경은 하지 않았다.
