# 운영자 회원 현황

운영 → 회원 현황에서 출석·1RM·NAMED WOD를 조회합니다. 이 화면은 승인된 운영자만 사용할 수 있으며, 일반 회원과 코치는 접근할 수 없습니다. API와 DB 함수에서도 운영자 역할을 확인합니다.

- 출석: 날짜별 출석/미출석, 선택한 달의 출석 일수·횟수 차감 합계, 현재 잔여 횟수, 회원별 전체 출석·차감·취소 이력을 확인합니다. 시간은 한국시간입니다.
- 1RM: 회원별·종목별 최고 중량, 최근 기록과 날짜, 전체 기록 이력을 봅니다. lbs/kg 표시를 바꿀 수 있습니다. 종목별로 집계하며 서로 다른 운동의 중량을 비교하지 않습니다. 확인된 종목 별칭은 기존 종목 목록에 맞춰 묶습니다.
- NAMED WOD: 시간 종목은 짧은 기록, 라운드 종목은 라운드·추가 횟수가 많은 기록을 최고로 표시합니다. 최근 기록과 과거 기록도 볼 수 있습니다.

이름 검색, 회원 상태, 출석/기록 유무, 종목 필터를 사용합니다. 기록이 없는 회원도 기본 목록에 표시됩니다. 회원 목록은 20명, 개인 이력은 50개씩 페이지를 넘깁니다. API는 기존 로그인 데이터의 1,000개 조회 제한을 사용하지 않으며 전체 건수를 DB에서 집계합니다.

이미 저장된 과거 출석·1RM·NAMED WOD도 다시 입력하지 않고 조회할 수 있습니다. 저장하지 않았거나 삭제한 기록을 새로 복원하지는 않습니다. 기존 기록의 수정 전 버전까지 보관하는 감사 이력 기능은 아닙니다.

회원 승인·권한 목록에서 이용 중인 기간권은 초록색, 횟수권은 선명한 주황색(#ff9b42), 휴회 중은 노란색으로 표시합니다. 휴회 표시가 회원권 종류보다 우선합니다. 이용 시작 전·만료·미등록은 기본 표시를 유지합니다. 횟수권 등록·연장의 추가 횟수 입력은 정수용 숫자 키패드를 요청합니다.

사진 자동 인식 설정과 외부 AI 연결을 제거했습니다. 사진 업로드/보관 및 GPS 출석 설정은 유지합니다. 사진의 텍스트를 붙여넣어 정리하는 기능은 보류 상태입니다.

## 적용

DB migration: `20261111212322_onoff_member_overview.sql`. 운영자 조회는 별도 읽기 전용 API로 제공하며 기본 로그인 응답에 전체 회원 기록을 추가하지 않습니다. 기존 원본 사진·기록을 삭제하지 않고, 외부 AI 호출과 쓰기 화면을 제거합니다.

## 검증

실제 PL/pgSQL을 격리된 PGlite/Postgres에서 실행해 운영자 권한, 과거 기록, 기록 없는 회원, 별칭별 1RM 최고·최근, NAMED WOD 시간/라운드 최고, 1,000개를 넘는 이력 페이지를 검증합니다. SQL fixture: `supabase/member-overview-tests.sql`.

`npm test`, `npm run build:backend`, `npm run build:cloudflare`, `npm run build`.
`python tests/browser/member-overview.py`, `python tests/browser/record-tools.py`는 실제 회원·알림에 영향을 주지 않는 가짜 인증/API 환경에서 휴대폰 UI를 검증합니다.
