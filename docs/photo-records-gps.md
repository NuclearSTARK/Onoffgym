# 사진 보관 · GPS 출석

사진 자동 인식·AI 초안·기록 변환 기능과 OpenAI 연결 설정을 제거했습니다. 텍스트 붙여넣기 자동 분류 방식은 검토 중이며 적용하지 않았습니다.

회원 기록 → 사진 올리기는 그대로 사용합니다. 날짜·수업을 선택해 칠판 원본 사진을 보관하고, 기존 사진도 열어볼 수 있습니다. 기존에 저장된 사진 및 기록 데이터는 삭제하지 않습니다. 과거에 등록 완료한 사진 유래 기록은 본인의 기록에서 읽기 전용으로 유지합니다.

운영 → GPS 출석에서 체육관 기준 위치·반경과 제한 사용 여부를 설정합니다. 회원은 체육관에서 출석 버튼 → 위치 권한 허용 → 출석 완료 순서로 사용합니다. 위치 확인 실패 시 출석·횟수 차감은 진행되지 않습니다. 실내 위치 오류는 운영자가 예외 출석 사유와 실제 방문 여부를 확인한 뒤 처리할 수 있습니다.

좌표는 출석 요청 때만 처리하며 회원의 위치를 계속 추적하거나 DB에 저장하지 않습니다. 하루 한 번 차감 및 출석 취소·동일 회원권 횟수 복구 규칙은 유지합니다.
