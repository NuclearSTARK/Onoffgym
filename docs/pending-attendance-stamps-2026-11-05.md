# 배포 대기: 둥근 출석 도장과 안내 중앙 정렬

2026-11-05 배포 지시로 이번 배포에 포함한다. 아래 배포 대기 표현은 구현 당시 기록이며, 최종 배포 기록은 [release-2026-11-05-gender-records-ui.md](release-2026-11-05-gender-records-ui.md)를 따른다.

2026-11-05 사용자가 출석 도장은 동그란 이모지만 다양하게 사용하고 랜덤 표시를 유지하며 하단 안내를 중앙 정렬하도록 요청했다. 로컬만 수정하고 배포하지 않았다.

- `ATTENDANCE_STAMPS`를 둥근 얼굴·공·달·원형 이모지 96종으로 교체했다. 기존 번개·트로피·근육·별 등은 제외했다.
- 회원 ID와 날짜에 기반한 기존 선택 함수를 그대로 유지한다. 같은 회원/날짜는 재접속해도 유지되고 회원·날짜별로 다양하게 표시된다. 목록 변경으로 과거 날짜도 새 원형 목록에서 표시되며 출석 데이터는 변경하지 않는다.
- `출석 버튼을 누른 날이 표시됩니다. 하루 한 번 출석할 수 있어요.` 문구만 `.attendance-help`로 중앙 정렬했다.
- 기존 도장 크기·정중앙 위치·불투명·회전 없음, 날짜와 오늘 테두리, 출석 처리 및 다른 이모지 목록은 유지했다.
- 기존 관련 Node 테스트 17개, Pages/Worker 빌드, diff 검사 통과. Playwright 모의 회원으로 28일 표시, 랜덤 다양성·재접속 일관성, 안내 정렬, 도장 투명도/회전 유지, 320/390/844px에서 패널·페이지 안 표시를 확인했다. 실제 회원/API 쓰기는 없다.
