## 현재 확인 결과

- 자동 테스트 59개 통과, 실패 0개.
- 실행 명령: `node --test --test-isolation=none tests/*.test.mjs`.
- 자동 테스트는 격리된 SQLite와 모의 로그인 정보·알림 전송을 사용한다. 실제 카카오 로그인이나 Supabase 운영 서버를 검증한 결과는 아니다.
- GitHub Pages 기본 화면은 Supabase 서버 연결과 승인된 Auth 세션을 사용하도록 변경했다. 카카오는 아직 미연결이다. 명시적인 `?preview=1` 예시 앱만 브라우저 저장 방식을 사용한다. 실제 회원 로그인·기기 간 공유 테스트는 사용자 요청대로 카카오 연결 후 진행한다.
- 순위 참여 ON/OFF 설정은 있지만 실제 등수 계산·자동 집계는 아직 미구현이다. 아래 순위 항목은 구현 및 실제 연결 후 검증할 예정이다.
- 앞서 브라우저로 확인한 모바일·TV 화면 결과는 실제 75인치 TV 브라우저의 리모컨·화면 배율·전체 화면 동작을 대신하지 않는다.

## 권장 준비

대표 소유의 카카오 개발자 앱과 Supabase 프로젝트를 만들고 개발자를 초대한다. 테스트가 끝날 때까지 개발자가 작업하고, 인수인계 시 대표가 관리자·복구 권한을 가진 상태를 확인한다. GitHub 저장소 소유권 이전이나 주소 변경 후에는 로그인 복귀 주소와 배포 경로를 다시 검사한다.

테스트 계정은 운영자 1명과 회원 2명 이상을 사용한다. 동명이인 시나리오를 위해 두 회원의 표시 이름을 같게 설정하되 계정은 다르게 만든다. 실제 휴대폰, PC와 체육관 TV로 함께 확인한다.

## 운영 정책을 확인할 항목

- 순위는 기록 입력·수정·삭제 및 참여 설정 변경에 따라 수시로 갱신한다. 마지막 수업까지 기록이 추가되면 당일 순위가 바뀔 수 있으며, 별도의 마감·확정 처리는 현재 요구사항에 없다. 동점 등수, 스케일 구분, 복합 기록의 집계 기준과 기기 간 갱신 방식은 구현 전에 확정한다.
- 현재 구현은 기존 승인 회원의 초기 설정을 위해 회원권 미등록 계정의 접근을 허용한다. 실운영 전 전체 회원권을 등록하거나, 미등록 계정의 접근 정책을 정하고 검증한다.
- 휴회는 실제 휴회 시작일부터 재개일까지의 한국 날짜 차이를 적용한다. 체육관에서 사용하는 휴회 최소·최대 기간과 소급 처리 정책을 확인한다.
- 실제 회원 데이터 공유, 카카오 세션, TV 공통 암호와 웹 푸시 예약 발송은 각 연결을 완료한 뒤 판정한다. 공개 데모의 동작만으로 실운영 통과 처리하지 않는다.

## 인수인계 완료 기준

1. 필수 항목을 실제 계정과 기기에서 확인하고, 실패 항목을 수정한 후 해당 흐름을 다시 검사한다.
2. 대표가 일상 운영 절차를 직접 한 번 이상 완료한다.
3. 서비스 소유권·배포 설정·복구 수단·백업과 운영 설명서를 대표에게 전달한다.
4. 오류 수정·기능 추가를 맡을 담당자와 처리 방법을 정한다.

Supabase의 적용 파일·권한·한도·카카오 후속 작업은 [연결 문서](supabase-connection.md)를 참고한다. SQL 테스트는 원자성·권한 검증이며 실사용자 로그인·동시 요청·장시간 TV 실기기 시험은 별도다.

- [x] 공지·로고·개인설정을 함께 고정. B/T↔WOD 스와이프 카드, S1/S2 별도 색·요약과 전체 보기, 중앙 3줄 푸터, 내비게이션 버튼 영역 축소. 최신 변경은 아래 항목을 따른다.
- [x] 커뮤니티 참여 수 표시·취소 반영, 홈 이외 화면의 별도 Challenge 문구 제거.
- [x] TV 상단 날짜·로고·시간 순서, 오늘 운동 배지 제거, 가로/Full HD 화면에서 넘침 검사. 최신 방향 설정은 아래 항목을 따른다.
- [x] 서버 푸시 예약 호출 정상 실행, 암호화/권한/구독 만료/기기 제한과 실제 테스트 API 검증. 카카오 없이 제한된 테스트 링크로 시험 가능.
- [ ] 실제 아이폰 홈 화면 앱과 안드로이드에서 알림 허용 후 앱을 닫고 잠금 화면 수신·알림 클릭·알림 해제 검증.


## 이번 수정 검증

- [x] 예시 앱 한 번 클릭으로 홈 진입, 균형 잡힌 개인설정 SVG.
- [x] B/T·WOD 선택부와 운동 내용을 일체형 카드로 연결, 영문 중복 제목·단위 전환 제거.
- [x] 휴강일·토요일 오픈짐만 있는 날은 시간표 숨김. 정규 수업일과 공휴일 특별 수업은 표시.
- [x] 공지 높이 축소, 모바일 하단 탭은 직전 57px에서 55.3px로 약 3% 축소. 하단 안전 여백 유지.
- [x] TV 기본 가로 1920×1080 캔버스 비율 유지. 운영 메뉴에서만 세로 1080×1920 선택, 화면에 맞춰 전체 축소해 잘림 방지. OS 화면 회전을 강제하지 않는다.
- [x] TV 로그인은 PC처럼 원본 로고 영역과 4자리 암호 입력 영역 분할.
- [x] 운영 → 푸시 알림 보내기: 제목·내용·미리보기·내 기기 시험·회원 발송·최근 이력. 예시 모드는 실제 발송 없이 이력만 현재 브라우저 저장.
- [x] 카카오 전 테스트 페이지에서도 직접 문구 작성, 소유 기기만 지연 발송. 운영자 외 전체 발송·이력 조회 거부, 테스트 코드로 전체 발송 불가.
- [ ] 사용자의 실제 휴대폰에서 알림 허용·앱 종료 후 수신과 알림 클릭 확인.
