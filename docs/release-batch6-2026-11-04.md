# ONOFF 배포 — 2026-11-04 요청

운동 번개 빨간 공지는 한국 시간의 운동 시작 시각에서 30분이 되는 순간 표시를 종료한다. 게시글·참여·댓글·기존 일반 공지는 유지한다. 서버 시각 기준으로 다음 만료 시각에 타이머를 예약하므로 모달/폼 작성 중에도 공지가 내려가며, 앱 재전환과 뒤로가기 복원 때도 재확인한다. 게시글을 삭제하거나 고정 설정을 데이터베이스에서 변경하지 않는다.

운동 영상 목록에서 영상 URL이 등록된 동작에만 제목 옆 ‘영상 연결’ 배지를 표시한다. 1RM 기본 표시 배지와 같은 스타일을 사용하고 미등록 동작에는 배지를 표시하지 않는다. 기존 수정·삭제 기능과 별칭 연결은 유지한다.

가로 화면에서도 실제 사이드바/본문 위치를 기준으로 고정 헤더의 시작점과 너비를 계산한다. ONOFF 문구의 시작선을 본문에 맞추고 오른쪽 아이콘과 공지 화살표는 안전 여백 안에 둔다. 회원 목록은 ‘휴회 중’ 문구를 제거하고 노란 원 테두리를 유지한다. 회원권·상세 버튼은 접근성 이름을 가진 눈 아이콘으로 바꾸고 행 중앙에 맞춘다.

TV 수요일 WOD 단독 화면은 가로 설정에서만 전체 폭 제목 바 아래 3열로 내용을 이어서 표시한다. 열 사이에는 얇고 은은한 회색 구분선과 여백을 둔다. 세로 설정과 다른 요일의 수업 구성은 유지한다. 고정 5줄 단위 분할 대신 실제 폰트/열 너비/높이에 맞춰 내용을 페이지로 나눈다. 같은 S1은 한 페이지 안에서 한 번만 표시하고 다음 페이지에 다시 표시한다. S2·S3 등 별개 구간 표시는 유지한다. 페이지 전환 시간은 기존 설정을 사용한다. 한글·이모지 및 연속 텍스트도 누락 없이 분할하며 폰트 로딩/크기 변경 뒤 다시 측정한다. 모든 요일·방향에서 하단 슬로건을 제거하고 표시 영역을 확장한다. 휴강/운동 준비 중 안내는 열 전체를 사용한다.

로딩 화면은 현재의 흰색 로고·파란 전원 기호·‘당신의 열정을 켜는 중…’ 문구로 통일했다. 뒤로가기 복원 시 이전 로딩 화면을 다시 재생하지 않는다. Pages 빌드에 공개 release.json/문서 버전을 추가해 복원된 문서가 구버전이고 작성 중인 내용이 없을 때 최신 문서를 불러온다. 작성 중인 폼은 자동 새로고침하지 않는다. 푸시 서비스 워커는 이전과 같이 회원 페이지/API를 캐시하지 않는다.

## 검증

- Node 테스트 150개 통과. 30분 경계·게시글 불변, 페이지/열 순서·구간 번호·텍스트 보존, 한글·이모지, 구버전 복원 시 폼 보호 포함.
- `qa-batch6.cjs`: 320–1920px, 휴대폰 가로/세로 및 안전 여백, 헤더/본문 정렬, URL 배지, 휴회 표시와 눈 아이콘, 모달 작성 중/재전환 시 공지 만료, 글 보존, 현재 로딩 문구 검사. 실제 회원 데이터 쓰기 없음.
- `qa-tv6.cjs`: 수요일/다른 요일 × 가로/세로, 긴 S1의 모든 페이지를 순회해 내용 보존·중복 번호·넘침 검사, 자동 전환, 3열 구분선, 하단 여백, 휴강 안내 검사.
- 기존 타이머/포인트/사진/모달/응답 경쟁/저장 공간 수동 갱신 검사를 `qa-release4.cjs`, `qa-audit.cjs`, `qa-storage.cjs`, `qa-collected.cjs`로 통과.
- Pages/Worker/Edge 패키지 빌드 및 git diff 검사 통과. 이번 변경은 프런트엔드 배포이며 서버 API·DB·인증·TV 비밀번호·실제 포인트/쿠폰·알림 구독 설정은 변경하지 않는다. 실제 시험 푸시도 발송하지 않는다.

검사는 Chromium 모의 모바일/데스크톱 환경에서 수행했으며 실물 휴대폰/TV 테스트는 포함하지 않는다.
