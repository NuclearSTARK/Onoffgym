## 카드와 날짜 선택

- 1RM 제목에 두 줄 높이를 확보하여 Deadlift 같은 한 줄 제목도 중량·날짜·구분선 위치가 맞는다. 제목 여백이 중복되어 좁은 화면에서 과도하게 줄바꿈되는 부분도 정리했다.
- 하단 `터치해 중량 계산`을 `중량계산`으로 변경했다. 중량계산·기록 모두 기존 기록의 12px 크기를 사용하며 각각 콘텐츠 왼쪽/오른쪽 끝에 맞춘다. 카드 전체 계산기 열기와 추가·이력·비교 버튼의 기존 동작을 유지한다.
- NAMED WOD는 시간형 카드에도 Cindy의 `라운드·횟수` 안내 줄 높이를 빈 줄로 예약해 날짜·구분선·하단 문구를 맞춘다. 운동 내용은 왼쪽, 기록 이력은 오른쪽이며 실제 버튼 순서도 이에 맞췄다. 320px 폭에서는 글자 크기를 줄이지 않고 카드 내부 여백을 조절해 두 버튼을 배치한다.
- 홈·회원 기록·ACC·날짜별 수업 등록의 오늘 버튼을 64px로 통일했다. 수정 전 실측에서 홈은 34/38px, 다른 세 화면은 56px였다. 수정 후 높이·오른쪽 끝·글꼴 크기·패딩·날짜 선택 박스 높이는 기존 값을 유지한다.

## 출석 달력

- 밝은 얼굴 24종과 사용자가 지정한 추가 16종을 정확히 사용해 총 40종으로 구성했다. 공 이모지와 기존 화남·울음·우울·아픔·졸림 표정은 제외했다. 지정된 성별·피부색 변형도 그대로 보존한다.
- 추가 16종: 👏 👊 💪 🔥 🏋️‍♂️ 🏋️ 🏋️‍♀️ 🏅 ✌️ 🤡 🤠 🫠 🫡 🏃‍♂️ 🏃🏻 🏆
- 기존 회원 ID/날짜 해시 선택 함수를 유지하여 재접속 시 같은 날짜의 도장이 유지된다. 목록 변경으로 과거 날짜의 도장도 새 목록에서 다시 표시되며 출석 데이터 자체는 변경하지 않는다.
- 오늘 원과 도장 컨테이너는 같은 날짜 중심을 유지한다. 도장 안에 고정된 글리프 칸을 두어 좁은 셀에서도 좌우 중앙을 맞추고 폰트의 보이는 그림이 아래로 치우치던 부분을 2px 위로 보정한다. 불투명·회전 없음·기존 크기와 안내 중앙 정렬을 유지한다. 수업 날짜 선택 달력의 도장 렌더링은 기존 방식을 유지한다.

## 개인정보와 개인설정

- 개인정보 화면의 안전 여백이 기존 모바일 `#main` 스타일에 덮여 24px로 남던 우선순위를 바로잡았다. 노치 여백과 최소 상단 여백에 20px 간격을 더해 문서 스크롤로 배치한다. 상세 펼침/접기·입력 검증·기존 동의 값은 유지한다.
- 개인설정 제목 오른쪽에 작은 이모지 버튼과 이름을 배치했다. 이모지 터치로 기존 변경창을 열며 즉시 갱신·저장 실패 시 복원·재접속 반영도 새 버튼에 연결했다. 큰 프로필 박스는 제거하고 이메일·권한·승인 상태는 계정 관리로 옮겼다. 회원카드가 첫 콘텐츠인 순서는 유지한다.
- 가로모드에서 개인설정 전체 패널·회원카드·쿠폰과 제목의 폭을 다른 탭과 같은 본문 폭으로 확대한다. 세로모드의 기존 카드/패널 폭과 카드 높이 380px를 유지한다. 기존 직원 지갑 표시 설정·계정 예외·카드 스와이프 및 데이터 접근은 변경하지 않는다.
- 왼쪽 메뉴의 운동 영상 항목을 제거했다. 기존 영상 라이브러리 경로·수업 내 영상·영상 관리 기능과 데이터는 유지한다.
