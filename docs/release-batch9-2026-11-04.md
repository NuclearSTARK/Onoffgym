# ONOFF 기록 비교·설정·가입 안내 정리

## 변경

- 1RM/NAMED WOD의 시상대 모양을 가로 막대그래프로 교체하고 기록 숫자 줄의 오른쪽 끝에 맞췄다. NAMED WOD 카드의 시간 단위 설명 `분:초`와 `기록 이력` 뒤 개수는 제거했다. 시간/라운드 입력과 기록 값은 유지한다.
- 비교 팝업은 퍼센트 오른쪽에 12px 구간 배지를 배치한다. 그 아래 15px·중간 굵기·왼쪽 정렬로 두 줄의 구간별 응원 문구를 넣는다. 중위권은 배지가 구간을 표현하므로 큰 글씨에서 중복 구간 문구를 줄였다. 계산 방식/공개 범위는 유지한다.
  - 상위권: 쌓아온 노력이 빛나요. / 다음 목표에 도전해보세요!
  - 중위권: 꾸준히 성장하고 있어요. / 한 걸음 더 나아가볼까요?
  - 하위권: 오늘의 기록부터, / 나의 속도로 차근차근!
- 커뮤니티 분류 5개는 같은 너비/높이의 한 줄로 정렬한다. `게시글 N개`는 아래 오른쪽에 별도로 표시한다.
- 휴강일 상태 카드의 글씨 크기/높이를 정상 수업 상태 카드와 통일하고 빈 운동 안내의 글씨/패딩/최소 높이를 정리한다.
- 로그인/가입/비밀번호 찾기 공통 상단에 노치 안전영역과 추가 여백을 확보한다. 승인 후 알림 안내는 아이폰(Safari, 홈 화면 앱, iOS 16.4+)과 안드로이드(Chrome 알림, 설치 선택)를 모두 설명하고 네이버/카카오 등 앱 안의 브라우저에서 외부 브라우저로 여는 방법을 안내한다.
- 회원 상태 원은 4px 안쪽 그림자로 처리해 스와이프 박스에 잘리지 않게 한다. 코치는 보라색, 운영자는 기존 파란색, 회원은 회색 배지로 구분한다.
- 공통 하단 구분선을 실제 본문 좌우 끝에 맞춘다. 네비게이션 바는 사용자 추가 요청에 따라 배경 80% 불투명도/블러로 조정하고 아이콘/문구는 투명하게 만들지 않는다.
- 공개 시각의 두 열 라벨/시간 높이, 안내 문구와 하단 전체 너비 저장 버튼을 정리한다. TV 설정은 좁은 화면에서도 색상/단위/전환 주기를 쌍으로 배치하고 접속 관리 구역을 분리한다. 공지 배너 설정은 입력/글자 수/색상 3버튼/미리보기/저장 간격과 크기를 맞춘다.

## 재참여 진단과 동작

실제 보고된 글은 작성자가 `email-signup-v1` 상태이고 현재 회원 간 공개 동의가 꺼져 있었다. 재참여자의 계정은 승인된 운영자이며 공개 동의와 회원권 상태에 문제가 없었다. DB의 기존 참여 함수가 비공개 작성자의 글에 새 참여를 차단하고, 이전 API가 이 원인을 일반 권한 오류로 바꾸고 있었다.

기존 회원의 공개 동의를 자동으로 켜거나 운영자가 타인의 선택 동의를 대신하도록 만들지 않았다. 작성자 본인이 새 개인정보 안내에서 공개를 허용해야 그 글에 새 참여가 가능하다. 화면에는 이 조건을 구체적으로 안내하고 `상태 다시 확인` 버튼을 제공한다. 본인의 공개 동의가 필요한 경우에는 해당 설정으로 이동할 수 있다. 회원권/승인/게시글 상태도 사전 확인해 의미 없는 일반 권한 오류 대신 이유를 표시한다.

`participationAccess`를 부트스트랩·참여 전 검사·상태 재확인에 공통 적용한다. 실제 참여 변경의 DB 권한 검사는 유지한다. 취소는 계속 가능하며, 공개 동의를 철회한 본인도 기존 참여를 알아볼 수 있도록 자기 참여 여부만 별도 플래그로 제공한다. 다른 비공개 참여자의 이름/ID는 추가 노출하지 않는다. 읽기 전용 상태 확인은 부트스트랩 캐시를 무효화하지 않는다. DB 스키마/동의 데이터 마이그레이션은 없다.

## 검증과 한계

- Node 170개 통과. 구간별 문구, 양 플랫폼 안내, 역할/동의/휴회·만료 조건, 작성자 확인 대기와 갱신 후 허용, 인증된 actor 사용, 비공개 본인 참여와 타인 정보 비노출 등을 포함한다.
- `qa-batch9.cjs`: 320px의 두 줄 문구와 세 구간 배지 정렬, 아이콘 오른쪽 정렬, 단위/개수 제거, 휴강일 크기, 필터 균등 배치, 참여·취소·재참여와 확인 대기/재확인, 설정 화면/원 테두리/배지/푸터, 양 플랫폼 승인 안내와 로그인 안전영역을 검증했다.
- `qa-batch8.cjs`, `qa-batch6.cjs`, `qa-collected.cjs` 회귀 통과. Worker/Edge/Pages 빌드 통과.
- `supabase/batch9-tests.sql`은 합성 Auth/회원/게시글을 만들어 승인된 운영자·코치·회원 각각의 실제 DB 함수 참여→취소→재참여 및 중복 방지를 확인하고 전부 롤백했다. 작성자 확인 전 차단/본인 확인 후 재참여 허용도 검증했다.
- Chromium의 iPhone/Android 사용자 에이전트·화면·터치·안전영역 모의 검사다. 물리적인 휴대폰에서 Safari/Chrome·OS 알림/키보드 동작을 직접 검사한 것은 아니다.
- 실제 회원 계정·동의·회원권·포인트·쿠폰·기록은 변경/삭제하지 않았다. 테스트 푸시/메일은 발송하지 않았으며 TV 암호와 이메일 확인 설정도 바꾸지 않았다. 배포 후 인증 없는 API 차단과 공개 파일/로그인 화면을 확인한다.
