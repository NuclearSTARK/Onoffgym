# 하단 탭바 스와이프와 스크롤 숨김

탭바 안에서 선택 배경을 좌우로 밀면 같은 방향의 인접 메뉴로 이동한다. 손가락을 따라 선택 배경이 움직이며, 한 번의 드래그로 한 메뉴만 이동하고 처음·마지막에서는 순환하지 않는다. 짧은 움직임·세로 스크롤·탭바 밖의 제스처는 메뉴를 바꾸지 않는다. 일반 터치 선택은 유지한다. 드래그가 취소되거나 멀티터치가 시작되면 현재 메뉴로 복귀하며, 드래그 뒤 생성되는 클릭으로 다른 메뉴가 열리지 않게 한다.

실제 이동은 기존 `go()`를 사용한다. 저장하지 않은 작성 내용을 버릴지 묻는 기존 확인 절차를 유지하고, 취소하면 유리 선택 배경도 원래 메뉴로 돌아온다. 회원 4개·운영자/코치 5개 메뉴와 기존 권한을 유지한다.

본문을 아래로 40px 연속 스크롤하면 탭바가 아래로 숨고, 위로 12px 올리면 다시 표시된다. 방향이 바뀌면 이동량을 새로 세어 작은 움직임에 반응하지 않는다. 페이지 위·아래 20px 안에서는 항상 표시하고, 탭 및 하위 페이지 이동 후에도 표시한다. 중첩 목록의 스크롤은 본문 스크롤로 처리하지 않는다. 키보드·팝업·사진 보기·화면 크기 변경·탭바 터치 중에는 숨김을 중지한다. 키보드 Tab 입력에서도 다시 표시한다. 숨겨진 바는 클릭과 포커스를 받지 않으며, 동작 줄이기 설정에서는 이동 애니메이션을 생략한다.

기존 63px 높이·가로 폭·하단 위치·R22·아이콘·메뉴명·세 테마는 유지한다. 화면 위치는 기존 visual viewport 계산으로 고정한다. DB·API 및 회원 데이터 변경은 없다.

## 검증

- 자동 테스트 220개 통과. 제스처 방향·임계값·끝점, 스크롤 방향 누적·작은 움직임·페이지 끝·차단 및 복귀 상태를 검증한다.
- Pages 및 Worker 빌드 통과.
- `qa-tab-bar-gestures.cjs`: Chromium 터치 이벤트로 드래그 추적, 좌우 이동, 끝점, 짧은 움직임, 드래그 취소·멀티터치, 직후 일반 터치, 세로/외부 스와이프, 작성 취소·승인, 실제 터치 스크롤, 숨김 후 화면 밖 위치와 접근 차단, 위로 스크롤 복귀, 페이지 양 끝, 중첩 목록, 탭 및 하위 페이지 전환, 키보드 Tab, 가로세로 전환, 회원 4개 메뉴와 세 테마, 동작 줄이기를 확인했다.
- `qa-nav-viewport.cjs`: 기존 화면 하단 고정, 키보드/팝업 종료 후 높이 복귀, 안전영역, 탄성 스크롤·확대·회전 검사를 통과했다.
- 브라우저 검증은 로컬 예시 API와 모의 viewport를 사용한다. 실제 회원 데이터·알림을 변경하지 않았으며 실제 iOS 기기 검증을 뜻하지 않는다. `ONOFF_QA_ORIGIN`으로 검증 대상의 공개 앱 주소를 지정할 수 있다.
