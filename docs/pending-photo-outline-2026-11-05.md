# 배포 대기: 사진 터치 후 포커스 테두리

2026-11-05 배포 지시로 이번 배포에 포함한다. 아래 배포 대기 표현은 구현 당시 기록이며, 최종 배포 기록은 [release-2026-11-05-gender-records-ui.md](release-2026-11-05-gender-records-ui.md)를 따른다.

사진을 터치하거나 확대 창을 닫은 뒤 사진 버튼에 남는 파란 포커스 테두리를 숨겼다. 공지·오늘의 기록·커뮤니티에서 공유하는 사진 갤러리에 적용된다. 이전 로컬 수정과 함께 배포 대기하며 운영 앱은 변경하지 않았다.

- `web/photos.js`: 사진 버튼의 pointerdown을 기록하고 키보드 입력 시 해제한다. 확대 창 종료 후 원래 버튼으로 포커스를 복원하는 동작은 유지한다.
- `web/polish13.css`: 터치/마우스로 선택한 사진 버튼만 outline/shadow를 숨기고 WebKit 탭 강조를 투명하게 처리한다. 키보드 포커스는 기존 3px 테두리를 유지한다. 사진 크기·정렬·확대/축소·삭제·API는 변경하지 않는다.
- 임시 Playwright 검증에서 터치→확대→닫기, 키보드 Tab→Enter→Escape, 다시 터치 순서를 확인했다. 브라우저가 터치 후에도 `:focus-visible`을 유지하는 경우를 강제로 재현해 테두리 제거를 확인했다. 실제 iPhone 검증은 수행하지 않았다.
- 기존 사진 관련 Node 테스트, Pages/Worker 빌드, `git diff --check` 통과. 실제 회원 데이터·사진/API 쓰기·배포 없음.
