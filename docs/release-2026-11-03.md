## 반영한 요청

- 운영 탭 저장공간을 아이콘 버튼으로만 수동 조회. 앱 복귀·탭 재진입·주기 갱신에는 마지막 결과와 카드 높이를 유지한다.
- 타이머: AMRAP/FOR TIME 분·초 입력, EMOM 초 간격, 누적 +1분/+30초/+10초 버튼, 시간 및 설정 재설정, 잘못된 분·초 입력 안내, MIX 구간 삭제 버튼 제거. TABATA는 유지한다.
- 타이머 준비 5·4·3·2·1초 신호와 시작 GO 음성·화면 표시, 더 또렷한 신호음, Arial 숫자, 큰 가로 모드 종목 제목. 음소거·화면 켜짐 유지·전체화면 기능 유지.
- 포인트 수동 지급에 회원 이름 검색과 차감 작업을 추가하고 화면 맨 아래로 이동. 지급·차감은 요청 ID로 중복 처리하지 않으며 잔액을 음수로 만들지 않는다.
- 적립 방식과 적립 항목의 추가·수정·삭제. 방식 이름과 연결 동작을 변경할 수 있다. 자동 적립 동작은 출석/개인 운동기록이며 새 활동은 운영자 선택 지급으로 관리한다. 방식 삭제 시 연결 항목의 지급을 중지하고 기존 회계 내역은 보존한다.
- 최근 발급 쿠폰을 간략하게 표시하고 5개 단위 스와이프 유지. 상점 제목·항목 행 정렬을 맞추고 좁은 화면의 버튼 잘림을 방지했다.
- 개인설정의 회원카드·쿠폰을 같은 너비·높이로 통일.
- 하단 메뉴 높이 5% 증가, 아이콘·문구의 상하 여백 정렬. 팝업을 위해 body 전체를 고정하던 처리를 제거하고 대화상자/스크롤 경계에서 배경 스크롤을 차단한다.
- 이용 중 회원은 이모지 테두리 초록색, 휴회 회원은 노란색. 이용 중 문구는 회원 행에서 제거하고 기간 정보는 유지한다.
- 사진은 인증된 최신 목록에 포함된 메모리 이미지를 재사용해 화면 갱신 시 재조회·깜박임을 줄였다.
- 1RM 대분류 추가·수정·삭제. 분류 삭제 시 다른 분류로 종목을 이동하며 종목 ID·기존 기록을 유지한다. 운동 영상 대분류와 독립적으로 관리한다.
- 중복 저장, 날짜 응답 역전/캐시 혼선, 로그아웃 후 늦은 응답, 20명 이후 기록 누락, 사진 확대창 중복·순서 역전·압축 취소 메모리 누수 등 점검에서 발견한 버그 수정.
