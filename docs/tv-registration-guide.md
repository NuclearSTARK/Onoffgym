# TV 앱 등록 안내

TV 모드에 접속한 뒤 **설정 → 앱 등록** 버튼을 누르면 별도의 회원용 설치 안내 화면이 열린다. 화면 선택 스위치나 운영 메뉴의 별도 실행 링크는 두지 않는다. TV 암호와 기존 TV 접속 정책은 그대로 적용된다.

가로 TV에서는 왼쪽에 큰 QR, 오른쪽에 아이폰 Safari·안드로이드 Chrome의 홈 화면 추가 방법과 알림 설정 순서를 표시한다. 세로 TV에서는 QR 영역을 위로 배치한다. 안내를 보는 동안에는 운동 페이지 자동 넘김을 멈춘다. 안내 오른쪽 위 **← 운동 화면** 버튼이나 Esc로 돌아오면 다시 시작한다. TV 모드에 새로 접속하거나 새로고침하면 운동 화면이 먼저 열린다. 안내는 앱 등록 버튼을 눌렀을 때만 연다.

QR은 체육관에서 제공한 이미지의 주소 `https://m.site.naver.com/2koh5`를 보존한 SVG다. 해당 주소가 `https://nuclearstark.github.io/Onoffgym/#home`으로 연결됨을 확인했다. TV 표시 크기에서도 선명하도록 벡터로 생성했고, 네 면에 4모듈의 여백을 두었다. 외부 QR 생성 서비스나 실행 시 QR 라이브러리를 사용하지 않는다.

안내에는 홈 화면의 ONOFF 실행, 개인설정의 알림 켜기, 휴대폰 알림 허용, 아이폰 홈 화면 앱·iOS 16.4 이상 조건, 카톡·네이버 안에서 열린 경우 외부 브라우저로 여는 방법을 포함한다.

## 확인

- `npm test`: 기존 213개 테스트 통과.
- `qa-tv-registration.cjs`: 1920×1080·1280×720·1080×1920에서 화면 배치, 설정의 앱 등록 버튼, 별도 안내 진입, 돌아가기·Esc, 안내 유지, 자동 넘김 재개, 서버 갱신, 운동 화면으로 새로고침, 크기 변경, TV 암호·연결 해제 확인. API는 로컬 예시만 사용한다.
- `qa-tv6.cjs`: 수요일/일반 수업의 가로·세로 페이지 분할과 자동 넘김, 휴강 화면 확인.
- 실제 렌더링된 QR을 세 가지 화면 크기에서 해독해 제공된 주소와 일치함을 확인.
- TV 설정에서 앱 등록을 열고, 안내의 돌아가기 버튼으로 복귀하는 경로 확인.

웹 파일만 수정하며 DB·서버 설정·TV 암호·회원 데이터·알림 구독을 바꾸지 않는다.
