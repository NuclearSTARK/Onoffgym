# ONOFF 화면·참여 취소·기록 비교 개선

- 운동 번개 참여 취소를 별도 서비스 RPC로 처리한다. 선택 공개 동의를 철회했거나 작성자가 공개를 중단했거나 회원권이 휴회/만료되어도 자신의 기존 참여는 취소할 수 있다. 새 참여의 공개/회원권 검사는 유지한다. 취소는 상태를 명시한 멱등 요청이며, 응답은 취소 확인만 반환해 비공개 게시물을 읽는 우회 경로가 되지 않는다. 버튼·인원·참여자 이름을 갱신하고 오류는 팝업 안에도 표시한다.
- 날짜 선택 양옆에 하루 이동 화살표, 같은 영역 안에 `오늘` 버튼을 유지한다. 오늘 날짜에서는 버튼을 비활성화하며 수업 공개 시각 제한은 유지한다. 오늘의 운동 관련 영상 뒤 아이콘은 유튜브 모양으로 통일한다.
- 1RM 상단 기록/종목 관리 버튼, 요약/단위 줄과 카드 제목 높이를 정렬한다. 중량 옆에 시상대 아이콘을 둔다. 기존 `내 기록` 관련 문구 변경은 취소 요청에 따라 추가 변경하지 않는다.
- 나의 기록 메뉴는 운영탭과 같은 2열 박스, 포인트는 전체 너비다. NAMED WOD 표기를 앱 전체에서 대문자로 통일하고 회원 카드 목록은 대분류 없이 표시한다. 카드 본문은 체육관 비교를, 하단의 `기록 이력 · 운동 내용`은 각 기능을 연다.
- NAMED WOD 비교는 승인·공개 동의·순위 참여 회원별 최고 기록 하나를 집계한다. 시간은 짧을수록, 라운드/횟수는 많을수록 높은 순위다. 동점은 동일 순위/백분위이며 순위, 비교 인원, 상대 위치 그래프를 표시한다. 다른 회원 이름/개별 기록을 반환하지 않는다. 기록자 부족/참여 꺼짐은 안내한다. 비교 조건은 회원이 같은 운동 조건으로 기록해야 한다.
- 내 NAMED WOD 종목 선택 팝업에 1RM과 같은 안내·검색·폰트·행 높이·구분선·스위치를 적용한다.
- 회원 관리 목록은 검색·상태/권한 필터를 적용한 결과를 10명씩 스와이프한다. 운동 영상·운영탭의 1RM/NAMED WOD 관리는 대분류별 한 페이지씩 스와이프한다. 영상의 분류 선택값과 현재 페이지는 함께 바뀐다.
- 회원 관리 이력 삭제는 운영자가 확인 후 선택한 이력 하나만 삭제한다. 대상 회원과 이력 ID를 서버에서 묶어서 검사한다. 실제 회원권/출석 상태와 다른 회원 이력은 바뀌지 않는다. 배포 중 실제 이력을 삭제하지 않았다.
- 개인정보 설정은 계정 관리 아래로 옮기고 제목/버튼 여백을 맞춘다. 설정에서 다시 연 동의 안내는 기존 동의 상태로 표시하며 X로 돌아올 수 있다. 최초 필수 안내와 선택 설정 화면의 상태를 분리한다.
- 로그인·가입·비밀번호 찾기와 미승인/초기 안내 화면에서는 하단 메뉴를 명시적으로 숨긴다. 비밀번호 입력에는 지우기 X 대신 표시/숨기기 눈 아이콘을 넣는다. 가입 비밀번호/확인, 재설정, 탈퇴/쿠폰 암호 등 공통 비밀번호 입력에 적용한다. 하단 메뉴는 배경 90% 불투명도와 블러를 적용하고 글씨/아이콘은 선명하게 유지한다.
- 운영 권한 배지를 제목 오른쪽으로 옮기고 회원 공개 화면 확인 버튼을 제거한다. 수업 등록에서 엑셀 일괄 등록 영역과 관련 설명을 제거하고 날짜/등록/복사/안내 정렬을 정리한다. 포인트 체험 영역을 제거하고 포인트 관리의 구역·제목/버튼·행/아이콘 정렬을 통일한다.

## 검증

- Node 테스트 165개 통과. 새 참여 취소 권한/검증된 사용자 식별자, NAMED WOD 집계 API, 이력 삭제 관리자/명시 확인/대상 검사를 포함한다.
- `qa-batch8.cjs`: 참여/취소/재열기, 날짜 이동/오늘/유튜브 아이콘, 2열 기록 메뉴, 1RM 도구/시상대, 평면 NAMED WOD/운동 내용/순위/선택 팝업, 회원 10명 페이지/검색/이력 삭제 확인, 대분류 스와이프, 수업/포인트 정리, 개인정보 위치/닫기, 320px/가로모드, 로그인 메뉴 숨김과 가입 확인 칸까지 눈 아이콘을 모의 API로 검증했다.
- `qa-batch7.cjs`, `qa-batch6.cjs`, `qa-collected.cjs`, `qa-storage.cjs` 회귀 통과. 기존 Named 관리 테스트는 변경한 대분류 페이지에서 검색 후 수정하도록 맞췄다.
- SQL 테스트는 합성 회원/게시글/기록으로 실행하고 롤백했다. 반복 참여/취소, 선택 동의 철회·휴회 후 취소, 다른 참여자 보존, 권한 없는 이력 삭제/대상 바꾸기 차단, 회원권 상태 유지, 시간/라운드·횟수 최고 기록·동점·옵트아웃·비공개·RPC 익명 권한을 확인했다.
- Worker/Pages/Edge 빌드 통과. 새 DB 보안 경고 없음. 기존 유출 비밀번호 보호 비활성화 경고만 유지한다. 가입 이메일 확인 설정과 TV 암호는 변경하지 않는다. 실제 회원/포인트/쿠폰/관리 이력 삭제 및 테스트 푸시/메일 전송은 하지 않았다.
- 브라우저 검사는 Chromium 모의 모바일/가로 환경이다. 실물 iPhone/Android의 터치·키보드 확인을 대체하지 않는다.
