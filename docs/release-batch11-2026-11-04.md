# ONOFF 구간별 순위·검색형 기록 입력·모바일 정리

기존 사진 미리보기·캐시·재시도, 하단 바 높이/투명도와 이전 화면 수정은 유지한다.

## 회원 기록

- 날짜·수업·기록 구간·필요한 입력 단위만 고른 뒤 회원 이름을 검색해 입력 목록에 추가한다. 첫 화면에는 전체 회원 명단을 만들지 않는다. 검색 결과는 최대 10명이며 검색어를 지우면 결과를 숨긴다. Enter로 첫 검색 결과를 추가할 수 있다. 선택한 회원만 화면과 저장 대상에 포함한다.
- 수업 시작 시간 선택을 제거하고 소제목을 `회원을 검색해 운동 기록을 입력하세요.`로 바꾼다. 새 기록은 시간 없는 일별 기록이다. 기존 기록이 하나면 ID와 저장된 시각을 유지해 수정하고, 여러 개면 수정할 기존 기록을 명시적으로 선택하게 하여 다른 기록을 덮거나 중복 생성하지 않는다.
- 빈칸은 기존 기록을 지우지 않는다. 기존 값 수정에는 체크 확인을 유지한다. 선택 회원/입력/메모는 날짜·수업·구간별로 유지하고, 중량 단위를 바꿔도 정밀한 기준 중량을 보존한다. 실제 변경 여부는 해당 입력 문맥에서 기록하여 다른 날짜로 이동해도 불필요한 경고나 입력 유실을 피한다. 계정 또는 편집 권한이 바뀌면 입력 임시 상태를 지운다.
- `전체 기록`은 이름순으로 한 회원의 S1·S2 등 기록을 함께 보여준다. `S1 순위`, `S2 순위` 등 기록 구간별 탭은 그 구간의 순위대로 표시한다. 각 탭은 회원 10명씩 좌우 스와이프와 페이지 표기를 제공한다. 한 회원의 구간 기록이 페이지 사이에 쪼개지지 않으며 순위 번호는 페이지별로 초기화하지 않는다.
- 횟수·칼로리·중량은 큰 값부터, 시간은 짧은 값부터, 라운드는 라운드 수 다음 추가 횟수, 완료 여부는 완료 먼저다. 세트별 횟수/칼로리는 합계로 비교하며 이를 화면에 안내한다. 동점은 1·1·3 방식의 공동 순위다. 비교할 수 없는 자유 문구와 서로 다른 기록 종류를 숫자 순위로 꾸미지 않는다.
- 같은 날짜·수업·구간·기록 종류에서 회원별 최고 기록 하나를 집계한다. 여러 시각에 남긴 과거 기록도 회원 수를 중복 집계하지 않는다. 순위에 사용하지 않은 기록은 전체 목록에서 그대로 확인할 수 있다.
- 서버는 현재 승인 상태·명시적인 회원 간 공개 동의·순위 참여 설정을 함께 확인한다. 운영자가 공개하지 않은 회원 기록을 관리 목적으로 볼 수 있어도 해당 기록은 순위 집계에 포함하지 않는다. 회원의 실제 동의/참여 설정을 바꾸지 않는다.

## 화면

- 달력 이모지 도장만 불투명도 40%(투명도 60%), 기울기 0°로 표시한다. 날짜 숫자와 달력에는 투명도를 적용하지 않는다.
- 코치의 기존 19개 세부 권한을 수업, 회원 기록·사진, 운동 영상·종목, 공지·알림, 운영 설정, ACC로 묶고 등록·수정·삭제를 같은 행에 배치한다. 코치 역할을 선택했을 때만 표시한다. 기본 권한/실제 허용 범위는 변경하지 않는다.
- 회원 이름·구분 메모 검색 라벨과 입력칸의 간격을 회원 상태 필드와 같은 8px로 맞춘다.
- 포인트 상점의 출석/개인 기록 적립 문구를 제거한다. `보유 포인트` 라벨을 나의 기록과 같은 `POINT` 및 글꼴/크기/색상/자간으로 통일한다. 포인트 내역은 5개씩 스와이프와 1 / N 표기를 검증했다.
- COMING UP 등 상태 카드의 오른쪽 곡선 잔선, 타임테이블 각 칸의 하단 둥근 잔선을 없앤다. 기존 왼쪽/상단 구분 색상은 유지한다. 선택한 WOD 시간 숫자와 선택 문구도 오렌지로 통일하며 OPEN GYM은 회색이다.

## 크리스마스

매년 한국시간 12월 25일에만 가벼운 눈송이와 가끔 지나가는 산타·루돌프 썰매 효과를 표시한다. 서버 예약이나 별도 외부 자산 요청은 없다. 효과 끄기를 제공하고 같은 날짜에는 그 기기에서 꺼진 상태를 기억한다. 개인설정에서 다시 켤 수 있으며 다음 해에는 자동으로 다시 활성화된다. 다른 날짜/비로그인/가입 안내에서는 표시하지 않고, 팝업/사진 확대/타이머 전체화면 중에는 숨긴다. 장식은 터치를 가로채지 않고 움직임 줄이기 설정도 따른다.

## 검증과 배포

- Node 테스트 193개: 구간별 정렬·동점·참여 제외·동명이인·같은 회원의 과거 시각 중복, 일별 입력·기존 시각 보존·명시적 기존 기록 선택·다른 회원/날짜/구간 차단, 권한 목록 보존, KST 연간 날짜 경계, 서버의 유효한 순위 참여 조건을 포함한다.
- `qa-batch11.cjs`: 320/390/844px에서 화면 간격, 도장 투명도/기울기, 코치 권한 묶음, 검색 후 추가/Enter/부분 저장/빈칸 보존, 새 일별 기록과 기존 기록 수정, 중량 단위 왕복과 임시 입력 보존, 구간별 전역 순위와 10명 페이지, 5개 포인트 내역, 수요일 오렌지색과 잔선 제거 확인.
- `qa-christmas11.cjs`: 날짜를 모의 설정하여 KST 경계/매년 재활성화/끄기 저장과 재개/터치 통과/팝업 숨김/움직임 줄이기 확인. 실제 기기 날짜와 회원 데이터는 바꾸지 않았다.
- 기존 `qa-batch9.cjs`, `qa-collected.cjs` 통과. 사진 첨부 부분 실패 재시도·분류·캐시·확대와 기존 화면 회귀를 확인했다. Chromium의 모바일 에뮬레이션이며 실물 아이폰·안드로이드 측정은 아니다.
- `npm test`, `npm run build`, `npm run build:pages`, `npm run build:backend` 통과. 실제 회원/기록/포인트/동의 변경·푸시 발송 없이 검증했다.
- 순위 참여 조건의 서버 응답을 갱신하며 기존 자체 Bearer 검증/비공개 사진 권한과 이메일 즉시 가입 설정은 유지한다. DB 스키마 변경은 없다.
