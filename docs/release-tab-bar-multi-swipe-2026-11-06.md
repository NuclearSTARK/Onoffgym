# 탭바 여러 칸 스와이프

한 번의 스와이프가 한 칸으로 제한되던 동작을 변경했다. 선택 배경이 손가락을 따라 탭바 전체 범위에서 이동하고, 손을 뗀 실제 선택 배경의 중심에서 가장 가까운 탭으로 이동한다. 길게 밀면 중간 페이지를 열지 않고 여러 칸을 건너뛴다. 이동 중 반대 방향으로 되돌리면 최종 위치를 기준으로 선택한다. 첫 탭과 마지막 탭에서는 경계를 넘어 순환하지 않는다.

기존 페이지 이동 절차를 사용하므로 저장하지 않은 내용의 이동 취소도 유지한다. 드래그 취소·멀티터치·작은 움직임·세로 스크롤·탭바 바깥 제스처의 처리, 일반 터치, 키보드 접근, 스크롤 숨김·복귀 및 기존 63px 높이·가로 폭·하단 위치·세 테마를 유지한다. DB·API 변경은 없다.

자동 테스트 227개와 Pages·Worker 빌드가 통과했다. `qa-tab-bar-gestures.cjs`에서 실제 터치 이벤트로 운영자 5개 메뉴의 2/3/4칸 이동, 4칸 이동 취소, 드래그 중 방향 전환, 미저장 작성 내용의 이동 거절·승인, 회원 4개 메뉴와 세 테마, 320/390/430/760px, 스크롤 숨김·복귀, 키보드·가로세로 전환과 동작 줄이기를 확인했다. `qa-nav-viewport.cjs`의 기존 화면 하단 고정 및 키보드 복귀 검사도 통과했다. 브라우저 검증은 예시 API만 사용해 실제 회원 데이터를 저장하거나 알림을 보내지 않았다.
