# 마감된 운동 번개 표시 보완

커뮤니티 카드 상단을 flex 행으로 묶어 운동 번개와 마감 배지를 같은 중심선·24px 높이로 맞췄다. 마감 배지는 빨간 바탕·흰색 굵은 글자·밝은 빨간 테두리로 표시한다. 마감된 글의 제목도 본문·사진과 같은 블러를 적용한다.

상세 화면은 제목 글자와 배지 영역을 나눠 제목만 흐려지고 마감 배지는 선명하게 유지한다. 작성자·날짜·번개 시간과 댓글 입력은 기존 처리를 유지한다. 30분 마감·배너 종료, 참여 차단·기존 참여 취소, 24시간 자동 정리 및 서버 설정은 변경하지 않는다.

자동 테스트 227개 및 Pages·Worker 빌드 통과. `qa-meetup-lifecycle.cjs`에서 320/390/760/1280px와 세 테마의 배지 중심선·동일 높이·색상·블러 범위를 검증했다. 일반 글 제목이 흐려지지 않고, 화면을 열어둔 채 마감 시각이 되어도 제목·본문 블러와 선명한 배지가 적용되는 것을 확인했다. 기존 배너 종료·24시간 목록 제거·참여 취소·작성 중 댓글 보존 검사도 통과했다. 검증은 예시 API만 사용했으며 실제 회원 게시글·사진을 수정하지 않았다.
