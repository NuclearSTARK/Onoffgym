휴대폰 푸시 테스트

회원 로그인 없이, 내 휴대폰 알림만 시험해요.

  1. 아이폰은 먼저 홈 화면에 추가한 앱으로 열어주세요.
  2. 테스트 코드를 확인하고 이 기기의 알림을 허용해주세요.
  3. 발송을 예약한 뒤 앱을 닫고 화면을 잠가주세요.

홈 화면 앱에서 코드가 비어 있으면 아래 코드를 복사해 붙여넣으세요. 설치 후 로그인 화면의 ‘휴대폰 푸시 테스트’로 들어오면 됩니다.
