# 보류했던 모바일 화면 수정 반영

- 출석 도장: 투명도와 기울기를 없애고 날짜 숫자의 정중앙에 겹친다. 달력과 날짜 숫자에는 투명도를 적용하지 않는다. 다양한 도장 선택은 유지한다.
- 코치 권한: 수업·ACC, 회원 기록·사진, 운동 콘텐츠, 공지·배너의 네 묶음으로 표시한다. 일부만 허용된 경우 혼합 상태를 보여주며 화면을 여는 것만으로 권한을 바꾸지 않는다. 실제 19개 권한 입력은 세부 조정에 보존한다. 삭제·푸시·공개 시각·TV는 묶음 토글에 포함하지 않는다. 회원·회원권·포인트 권한과 서버 권한 검증은 유지한다.
- 일괄 입력: 날짜 아래 및 구간 요약 위 16px 간격을 두고 날짜·수업/구간·회원 검색의 양쪽 끝을 맞춘다. 최근 도입한 구조화 입력도 행 전체 폭을 사용한다.
- 개인 운동 기록: 최신 날짜부터 정렬하고 날짜를 결과 위에 표시한다. S1/S2 배지와 우측 연필 버튼으로 바꾸며 행 높이를 줄인다. 메모와 긴 결과를 보존하고 10개씩 좌우 스와이프와 페이지 표시를 제공한다.
- 회원 순위: 구간별 순위를 프로필 이모지 왼쪽으로 옮긴다. 실제 공동 순위 번호에 따라 1/2/3위는 메달, 4위부터는 텍스트로 표시하고 연필은 우측 끝에 둔다. 전체 기록에서는 서로 다른 구간의 순위를 하나로 합치지 않는다. 수업·날짜·구간을 바꿀 때 사용 가능한 운동 조건을 선택하여 이전 RX 필터 때문에 기록이 비어 보이는 현상을 막는다.
- 크리스마스: 매년 한국시간 12/24와 12/25에만 눈과 승인된 투명 배경 일러스트를 사용한다. 옛 이모지 산타·루돌프를 제거한다. 일러스트는 하단 네비게이션 바로 위를 가끔 지나간다. 비로그인/다른 날짜에는 이미지 요청을 만들지 않으며 터치 통과·효과 끄기·팝업 숨김·움직임 줄이기를 유지한다.

검증: Node 204개, `qa-polish13.cjs`(320/390/844px, 실제 Chromium touch 이벤트로 기록 페이지 이동, 도장 중심 좌표/불투명도, 16px 간격과 정렬, 권한 보존과 묶음 토글 범위, 10개 기록, 메달·연필 좌표), `qa-record12.cjs`(개인/일괄 입력·순위 호환), `qa-christmas11.cjs`(KST 날짜 경계/이미지/효과/접근성), `qa-collected.cjs`(사진·게시글 등), Worker 및 Pages 빌드.

회원·기록·포인트·동의·코치 권한의 실제 데이터는 테스트로 변경하지 않는다. 이번 수정은 프런트엔드 배포이며 Supabase API v27과 스키마를 유지한다. 최근 기록 입력 양식, 사진 캐시/미리보기, 하단 바 높이와 투명도를 보존한다. 물리적인 휴대폰 검증은 수행하지 않았다.
