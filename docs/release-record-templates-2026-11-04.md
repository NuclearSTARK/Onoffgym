# 구간별 기록 입력 양식

운영자가 수업 구간의 기록 종류와 순위 정책을 지정한다. 개인 입력과 회원 기록 일괄 입력은 같은 양식과 검증을 사용한다.

- 시간은 완료(분·초) / 타임캡(구간에 지정한 횟수·칼로리·라운드+횟수)로 나눈다. 완료자 시간순, 타임캡 수행량순으로 비교한다.
- 횟수·칼로리는 정수, 라운드와 추가 횟수는 별도 정수, 중량은 canonical lbs, 완료 여부는 선택값으로 저장한다.
- 세트별·자유 기록은 상세 결과를 보존한다. 기본 정책은 순위 없음이며, 운영자가 별도 비교 숫자의 이름과 큰 값/작은 값 우선 기준을 지정할 수 있다. 상세 문자열에서 합계를 추정하지 않는다.
- RX / Scaled는 구간별로 별도 집계한다. 과거 기록에는 조건을 임의 지정하지 않고 미분류 그룹을 유지한다. 기존 공개 동의·순위 참여 검사를 유지한다.
- 서버가 canonical 수업 정책으로 결과를 검증하고 표시값과 비교 정책 키를 생성한다. 다른 정책으로 저장된 결과는 현재 순위에서 제외한다.
- 기존 자유 형식 기록은 삭제·일괄 변환하지 않는다. 일괄 입력의 기존 ID/수업 시간 보존, 중복 기록 선택, 덮어쓰기 확인, 빈칸 보존과 계정별 초안을 유지한다.

기록/수업 JSONB의 기존 저장 구조를 사용하며 DB 마이그레이션이나 회원 데이터 변경은 없다. Supabase API 번들과 Pages를 함께 배포한다. 기존 클라이언트의 legacy 요청은 호환하며 새 기록을 RX로 추정하지 않는다.

검증: Node 테스트 204개, mock Auth/API를 사용하는 모바일 기록 입력 QA, 기존 사진·게시글·운영 컨트롤 QA, 크리스마스 효과 회귀 QA, Worker/Edge/Pages 빌드. 실제 회원 계정이나 기록을 이용한 쓰기 테스트는 하지 않는다.

출석 도장·권한 화면 단순화·회원 기록의 메달/연필 배치·개인 기록 목록 압축·일괄 입력 외곽 여백·크리스마스 새 일러스트는 보류 요청대로 포함하지 않는다.
